# [SOURce<HW>]:BB:C2K:MSTation:PRESet
driver.source.bb.c2K.mstation.preset()
driver.source.bb.c2K.mstation.preset_with_opc(opc_timeout_ms = 3000)

A standardized default for all the mobile stations (*RST values specified for the commands) . See ‘Reset All Mobile Stations’ for an overview.

preset_with_opc() does the same as preset(), but waits for the operation to complete before continuing further. Use the RsSmw.utilities.opc_timeout to set the timeout value.

Parameters:

opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.
