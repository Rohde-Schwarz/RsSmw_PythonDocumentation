Enters the dwell time values in the selected list in us.

Parameters:

dwell – Dwell#1{, Dwell#2, …} | block data You can either enter the data as a list of numbers, or as binary block data. The list of numbers can be of any length, with the list entries separated by commas. In binary block format, 8 (4) bytes are always interpreted as a floating-point number with double accuracy. See also method RsSmw.formatPy.data() for more details.
