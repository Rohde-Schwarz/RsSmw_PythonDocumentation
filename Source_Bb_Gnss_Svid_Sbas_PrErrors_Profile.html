# [SOURce<HW>]:BB:GNSS:SVID<CH>:SBAS:PRERrors:PROFile<GR>:DELete
driver.source.bb.gnss.svid.sbas.prErrors.profile.delete(satelliteSvid = repcap.SatelliteSvid.Default, index = repcap.Index.Default)
driver.source.bb.gnss.svid.sbas.prErrors.profile.delete_with_opc(satelliteSvid = repcap.SatelliteSvid.Default, index = repcap.Index.Default, opc_timeout_ms = 3000)

Deletes the selected pseudorange error.

delete_with_opc() does the same as delete(), but waits for the operation to complete before continuing further. Use the RsSmw.utilities.opc_timeout to set the timeout value.

Parameters:

  • satelliteSvid – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Svid’)

  • index – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Profile’)

  • opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.
