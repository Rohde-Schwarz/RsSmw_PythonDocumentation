Enters the level values in the selected list. The number of level values must correspond to the number of frequency values. Existing data is overwritten.

Parameters:

power – Power#1{, Power#2, …} | block data You can either enter the data as a list of numbers, or as binary block data. The list of numbers can be of any length, with the list entries separated by commas. In binary block format, 8 (4) bytes are always interpreted as a floating-point number with double accuracy. See also method RsSmw.formatPy.data() . Range: depends on options , Unit: dBm
