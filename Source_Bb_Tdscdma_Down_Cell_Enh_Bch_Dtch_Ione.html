Ione#

SCPI Command :

[SOURce<HW>]:BB:TDSCdma:DOWN:CELL<ST>:ENH:BCH:DTCH<CH>:IONE
Commands in total: 1
Subgroups: 0
Direct child commands: 1
get ( cell=Cell.Default, channel=Channel.Default ) → bool
set ( ione: bool, cell=Cell.Default, channel=Channel.Default ) → None
# [SOURce<HW>]:BB:TDSCdma:DOWN:CELL<ST>:ENH:BCH:DTCH<CH>:IONE
# get:
value: bool = driver.source.bb.tdscdma.down.cell.enh.bch.dtch.ione.get(cell = repcap.Cell.Default, channel = repcap.Channel.Default)
# set:
driver.source.bb.tdscdma.down.cell.enh.bch.dtch.ione.set(ione = False, cell = repcap.Cell.Default, channel = repcap.Channel.Default)

Activates or deactivates the channel coding interleaver state 1 and 2 off all the transport channels. Interleaver state 1 and 2 can only be set for all the TCHs together. Activation does not change the symbol rate.

Parameters:

  • ione – 1 | ON | 0| OFF

  • cell – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Cell’)

  • channel – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Dtch’)
