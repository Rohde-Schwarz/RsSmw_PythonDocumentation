# [SOURce<HW>]:BB:GNSS:LOGGing:CATegory:SATellite:SELect:NONE
# set:

# set_with_opc:
driver.source.bb.gnss.logging.category.satellite.select.nonePy.set_with_opc(opc_timeout_ms = 3000)

Enables or disables all of the available SV IDs.

set_with_opc() does the same as set(), but waits for the operation to complete before continuing further. Use the RsSmw.utilities.opc_timeout to set the timeout value.

Parameters:

opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.
