# [SOURce<HW>]:BB:EUTRa:UL:UE<ST>:PUCCh:F1Naport
# get:
value: enums.PucchNumAp = driver.source.bb.eutra.uplink.ue.pucch.f1Naport.get(userEquipment = repcap.UserEquipment.Default)
# set:
driver.source.bb.eutra.uplink.ue.pucch.f1Naport.set(num_aps = enums.PucchNumAp.AP1, userEquipment = repcap.UserEquipment.Default)

For LTE-A UEs, sets the number of antenna ports used for every PUCCH format transmission.

Parameters:

  • num_aps – AP1 | AP2

  • userEquipment – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Ue’)
