Gain#

SCPI Command :

[SOURce<HW>]:BB:EVDO:TERMinal<ST>:RRIChannel:GAIN
Commands in total: 1
Subgroups: 0
Direct child commands: 1
get ( terminal=Terminal.Default ) → float
set ( gain: float, terminal=Terminal.Default ) → None
# [SOURce<HW>]:BB:EVDO:TERMinal<ST>:RRIChannel:GAIN
# get:
value: float = driver.source.bb.evdo.terminal.rriChannel.gain.get(terminal = repcap.Terminal.Default)
# set:
driver.source.bb.evdo.terminal.rriChannel.gain.set(gain = 1.0, terminal = repcap.Terminal.Default)

(enabled for an access terminal working in traffic mode) Sets the gain of the Reverse Rate Indicator (RRI) channel relative to the pilot channel power.

Parameters:

  • gain – float Range: -80 to 10 dB

  • terminal – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Terminal’)
