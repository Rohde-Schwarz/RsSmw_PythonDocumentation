# [SOURce<HW>]:BB:PRAMp:PRESet
driver.source.bb.pramp.preset()
driver.source.bb.pramp.preset_with_opc(opc_timeout_ms = 3000)

Sets the parameters of the power sweep to their default values (*RST values specified for the commands) . Not affected is the state set with the method RsSmw.source.bb.pramp.state() .

preset_with_opc() does the same as preset(), but waits for the operation to complete before continuing further. Use the RsSmw.utilities.opc_timeout to set the timeout value.

Parameters:

opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.
