Execute#

SCPI Command :

[SOURce<HW>]:BB:GNSS:SVID<CH>:BEIDou:POWer:COPY:EXECute
Commands in total: 1
Subgroups: 0
Direct child commands: 1
set ( satelliteSvid=SatelliteSvid.Default ) → None
set_with_opc ( satelliteSvid=SatelliteSvid.Default, opc_timeout_ms: int = -1 ) → None
# [SOURce<HW>]:BB:GNSS:SVID<CH>:BEIDou:POWer:COPY:EXECute
# set:
driver.source.bb.gnss.svid.beidou.power.copy.execute.set(satelliteSvid = repcap.SatelliteSvid.Default)
# set_with_opc:
driver.source.bb.gnss.svid.beidou.power.copy.execute.set_with_opc(satelliteSvid = repcap.SatelliteSvid.Default, opc_timeout_ms = 3000)

Applies the configuration of the current satellite (SVID<ch>:<GNSS system>) to the satellite defined with the method RsSmw.source.bb.gnss.svid.gps.power.copy.svid.set() . Both SV IDs belong to the same GNSS system.

set_with_opc() does the same as set(), but waits for the operation to complete before continuing further. Use the RsSmw.utilities.opc_timeout to set the timeout value.

Parameters:

  • satelliteSvid – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Svid’)

  • opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.
