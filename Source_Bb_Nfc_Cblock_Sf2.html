# [SOURce<HW>]:BB:NFC:CBLock<CH>:SF2
# get:
value: str = driver.source.bb.nfc.cblock.sf2.get(commandBlock = repcap.CommandBlock.Default)
# set:
driver.source.bb.nfc.cblock.sf2.set(sflag_2 = rawAbc, commandBlock = repcap.CommandBlock.Default)

Sets the status flag 2 to specify a Type 3 tag’s error condition. A value of 0 signals a successful execution, values different from 0 indicate errors.

Parameters:

  • sflag_2 – integer

  • commandBlock – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Cblock’)
