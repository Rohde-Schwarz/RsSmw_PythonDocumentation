# [SOURce<HW>]:FSIMulator:MIMO:TAP<CH>:GVECtor:PRESet
driver.source.fsimulator.mimo.tap.gvector.preset(mimoTap = repcap.MimoTap.Default)
driver.source.fsimulator.mimo.tap.gvector.preset_with_opc(mimoTap = repcap.MimoTap.Default, opc_timeout_ms = 3000)

Presets the vector matrix to a unitary matrix.

preset_with_opc() does the same as preset(), but waits for the operation to complete before continuing further. Use the RsSmw.utilities.opc_timeout to set the timeout value.

Parameters:

  • mimoTap – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Tap’)

  • opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.
