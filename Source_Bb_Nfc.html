preset ( ) → None

# [SOURce<HW>]:BB:NFC:PRESet
driver.source.bb.nfc.preset()
driver.source.bb.nfc.preset_with_opc(opc_timeout_ms = 3000)

Sets the parameters of the digital standard to their default values (*RST values specified for the commands) . Not affected is the state set with the command SOURce<hw>:BB:NFC:STATe.

preset_with_opc() does the same as preset(), but waits for the operation to complete before continuing further. Use the RsSmw.utilities.opc_timeout to set the timeout value.

Parameters:

opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.
