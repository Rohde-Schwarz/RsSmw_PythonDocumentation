Sets the designated PRACH preamble format. The preamble is used to obtain the UL synchronization. In 5G NR, there are 64 preambles defined in each time-frequency PRACH occasion. The preamble consists of two parts cyclic prefix (CP) and preamble sequence. In 5G NR, there are 13 types of preamble format supported known as format 0, format 1, format 2, format 3, format A1, format A2, format A3, format B1, format B2, format B3, format B4, format C0, format C1.

Parameters:

prach_format – F0 | FA1 | FA2 | FA3 | FB4 | FC0 | FC2
