Sets the 20-bit Search-and-Rescue Service (SAR) return link message (RLM) data for nominal mode operation. For more information, refer to specification Galileo OS SIS ICD.

Parameters:

  • sar_rlm_data – integer Range: 0 to 1048575

  • satelliteSvid – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Svid’)

  • index – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Rlm’)
