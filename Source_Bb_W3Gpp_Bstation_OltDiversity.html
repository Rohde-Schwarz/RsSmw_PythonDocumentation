Subgroups: 0

# [SOURce<HW>]:BB:W3GPp:BSTation<ST>:OLTDiversity
# get:
value: bool = driver.source.bb.w3Gpp.bstation.oltDiversity.get(baseStation = repcap.BaseStation.Default)
# set:
driver.source.bb.w3Gpp.bstation.oltDiversity.set(olt_diversity = False, baseStation = repcap.BaseStation.Default)

Activates/deactivates open loop transmit diversity. The antenna whose signal is to be simulated is selected with the method RsSmw.source.bb.w3Gpp.bstation.tdiversity.set() .

Parameters:

  • olt_diversity – ON | OFF

  • baseStation – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Bstation’)
