Dselect#

SCPI Command :

[SOURce<HW>]:BB:TDSCdma:DOWN:CELL<ST>:ENH:BCH:DTCH<CH>:DATA:DSELect
Commands in total: 1
Subgroups: 0
Direct child commands: 1
get ( cell=Cell.Default, channel=Channel.Default ) → str
set ( dselect: str, cell=Cell.Default, channel=Channel.Default ) → None
# [SOURce<HW>]:BB:TDSCdma:DOWN:CELL<ST>:ENH:BCH:DTCH<CH>:DATA:DSELect
# get:
value: str = driver.source.bb.tdscdma.down.cell.enh.bch.dtch.data.dselect.get(cell = repcap.Cell.Default, channel = repcap.Channel.Default)
# set:
driver.source.bb.tdscdma.down.cell.enh.bch.dtch.data.dselect.set(dselect = 'abc', cell = repcap.Cell.Default, channel = repcap.Channel.Default)

Selects an existing data list file from the default directory or from the specific directory. For general information on file handling in the default and in a specific directory, see section ‘MMEMory Subsystem’ in the R&S SMWuser manual. For the traffic channels, this value is specific for the selected radio configuration.

Parameters:

  • dselect – string

  • cell – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Cell’)

  • channel – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Dtch’)
