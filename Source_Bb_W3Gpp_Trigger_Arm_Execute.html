# [SOURce<HW>]:BB:W3GPp:TRIGger:ARM:EXECute
# set:
driver.source.bb.w3Gpp.trigger.arm.execute.set()
# set_with_opc:
driver.source.bb.w3Gpp.trigger.arm.execute.set_with_opc(opc_timeout_ms = 3000)

Stops signal generation; a subsequent trigger event restarts signal generation.

set_with_opc() does the same as set(), but waits for the operation to complete before continuing further. Use the RsSmw.utilities.opc_timeout to set the timeout value.

Parameters:

opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.
