IviDirectIo#

class IviDirectIo

Direct IO class required by the IVI-Python standard.

read_bytes ( ) → bytes

Read a complete response from the instrument as bytes. The response message terminator is not included in the bytes object.

read_string ( ) → str

Read a complete response from the instrument as a string. The response message terminator is not included in the string.

write_bytes ( data: bytes ) → None

Write bytes to the instrument followed by the normal message termination sequence. For IEEE 488.2 instruments the termination sequence is typically a line feed character with END asserted. The bytes must include a complete instrument message. The driver adds the termination sequence.

write_string ( data: str ) → None

Write a string to the instrument followed by the normal message termination sequence. For IEEE 488.2 instruments the termination sequence is typically a line feed character with END asserted. The string must include a complete instrument message. The driver adds the termination sequence.

sync_from ( source: IviDirectIo ) → None

Synchronizes this object with the source.
