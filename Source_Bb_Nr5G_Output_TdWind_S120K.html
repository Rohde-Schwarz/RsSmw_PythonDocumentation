get_tr_time ( ) → float
# [SOURce<HW>]:BB:NR5G:OUTPut:TDWind:S120K:TRTime
value: float = driver.source.bb.nr5G.output.tdWind.s120K.get_tr_time()

Sets the transition time when time domain windowing is active. The next to last block in the command syntax indicates the used SCS and CP combination.
