IviUtility#

class IviUtility

Utilities class required by the IVI-Python standard.

reset ( ) → None

Resets the instrument and clears its status. This is typically done by sending the *RST and *CLS SCPI Commands.

error_query ( ) → ErrorQueryResult | None

Returns the last error in the instrument’s error queue. Returns None if no error is present.

Note: If status-error suppression rules are configured (see status_error_suppression_add_rule()), errors matching those rules are filtered out and will not be returned.

error_query_all ( ) → List[ErrorQueryResult]
Returns all the errors currently reported in the instrument’s error queue.

If no error is present, the method returns an empty collection.

Note: If status-error suppression rules are configured (see status_error_suppression_add_rule()), errors matching those rules are filtered out and will not appear in the returned collection.

raise_on_device_error ( ) → None

Calls error_query_all() and raises an exception if any instrument errors were detected.

sync_from ( source: IviUtility ) → None

Synchronizes this object with the source.
