# [SOURce<HW>]:BB:KUIPer:REFSignal:FILTer:CATalog
value: List[str] = driver.source.bb.kuiper.refSignal.filterPy.get_catalog()

Queries a filtered selection of reference signal files. Listed are files that remain after filtering for a group of reference signal files that contain a defined string in their filename. Set this filter via the following command: method RsSmw.source.bb.kuiper.refSignal.filterPy.name() If no filter applies, the query returns a string with all reference signal files.

Returns:

kuiper_cat_name_ref_sig_modified: string Returns a string of filenames separated by commas.
