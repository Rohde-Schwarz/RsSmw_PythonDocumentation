Selects the data list when the DLISt data source is selected for the TPC start pattern of the DPCCH. The files are stored with the fixed file extensions dm_iqd in a directory of the user’s choice. The directory applicable to the commands is defined with the method RsSmw.massMemory.current_directory() . To access the files in this directory, only the file name has to be given, without the path and the file extension.

Parameters:

dselect – data_list_name
