# [SOURce<HW>]:BB:NR5G:TRIGger:OUTPut<CH>:DUPLexing
value: enums.EutraDuplexMode = driver.source.bb.nr5G.trigger.output.duplexing.get(output = repcap.Output.Default)

Defines the duplexing mode for a UL/DL pattern containing a marker.

Parameters:

output – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Output’)

Returns:

duplexing: TDD | FDD TDD Sets TDD (time division duplex) as the duplexing mode. FDD Sets FDD (frequency division duplex) as the duplexing mode.
