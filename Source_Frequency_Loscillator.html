Selects the mode of the local oscillator coupling. Cross-reference between <Mode> and the manual operation <Mode> / Parameter in manual operation / Description - INTernal / A&B Internal / Internal (one path instrument) / Uses the internal oscillator signal in both paths. - EXTernal / A External & B Internal (one path instrument) / Uses an external signal in path A. B uses its internal signal. - COUPled / A Internal & A->B Coupled / Assigns the internal oscillator signal of path A also to path B. - ECOupled / A External & A->B Coupled / Assigns an externally supplied signal to both paths. - BOFF / A Internal & B RF Off / Uses the internal local oscillator signal of path A, if the selected frequency exceeds the maximum frequency of path B. - EBOFf / A External & B RF Off / Uses the LO IN signal for path A, if the selected RF frequency exceeds the maximum frequency of path B. - AOFF / A RF Off & B External / Uses the LO IN signal for path B, if the selected RF frequency exceeds the maximum frequency of path A.

Parameters:

mode – INTernal | EXTernal | COUPled | ECOupled | BOFF | AOFF See Table ‘Cross-reference between Mode and the manual operation’
