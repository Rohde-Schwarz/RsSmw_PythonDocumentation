Ontime#

SCPI Command :

[SOURce<HW>]:BB:TETRa:TRIGger:OUTPut<CH>:ONTime
Commands in total: 1
Subgroups: 0
Direct child commands: 1
get ( output=Output.Default ) → int
set ( ontime: int, output=Output.Default ) → None
# [SOURce<HW>]:BB:TETRa:TRIGger:OUTPut<CH>:ONTime
# get:
value: int = driver.source.bb.tetra.trigger.output.ontime.get(output = repcap.Output.Default)
# set:
driver.source.bb.tetra.trigger.output.ontime.set(ontime = 1, output = repcap.Output.Default)

Sets the duration during which the marker output is on or off. If R&S SMW-B9 is installed, the minimum marker duration depends on the sample/symbol rate. See ‘Marker Minimum Duration’.

Parameters:

  • ontime – integer Range: 1 (R&S SMW-B10) / 1* (R&S SMW-B9) to 16777215

  • output – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘Output’)
