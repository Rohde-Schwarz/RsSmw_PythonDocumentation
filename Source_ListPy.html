# [SOURce<HW>]:LIST:DELete:ALL
driver.source.listPy.delete_all()

Deletes all lists in the set directory. This command can only be executed, if:

  • No list file is selected.

  • List mode is disabled.

delete_all_with_opc() does the same as delete_all(), but waits for the operation to complete before continuing further. Use the RsSmw.utilities.opc_timeout to set the timeout value.

Parameters:

opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.
