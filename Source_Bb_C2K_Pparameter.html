# set:
driver.source.bb.c2K.pparameter.set_crest(crest = enums.CresFactMode.AVERage)

This command selects the desired range for the crest factor of the test scenario. The crest factor of the signal is kept in the desired range by automatically setting appropriate Walsh codes and timing offsets. The setting takes effect only after execution of command method RsSmw.source.bb.c2K.pparameter.execute.set() . The setting of command method RsSmw.source.bb.c2K.bstation.cgroup.coffset.wcode.set() is adjusted according to the selection.

Parameters:

crest – MINimum | AVERage | WORSt MINimum The crest factor is minimized. The Walsh codes are spaced as closely as possible. AVERage An average crest factor is set. The Walsh codes are distributed uniformly over the code domain. WORSt The crest factor is set to an unfavorable value (i.e. maximum) . The Walsh codes are as wildly spaced as possible.
