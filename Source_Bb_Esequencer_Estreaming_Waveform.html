Queries information about the current I/Q stream in a comma-separated list. The table below list all parameters that are queried. Parameter / Description - Clock / Clock rate in Hz - Peak level / RF signal peak level - RMS level / RF signal RMS level - Request buffer size / Currently required buffer size for I/Q streaming
