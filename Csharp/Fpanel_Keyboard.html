Fpanel:Keyboard#

SCPI Commands

Direct SCPI Members

FrontPanelLayoutEnum Layout#
// SCPI: FPANel:KEYBoard:LAYout
FrontPanelLayoutEnum value = driver.Fpanel.Keyboard.Layout;
driver.Fpanel.Keyboard.Layout = FrontPanelLayoutEnum.DIGits;

Selects the layout of the front panel keypad.

layout: DIGits | LETTers DIGits Enables numerical keys only. LETTers Enables numerical and alphanumerical keys.
