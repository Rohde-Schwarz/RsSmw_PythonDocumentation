Direct SCPI Members

double Delay#
// SCPI: [SOURce<HW>]:PULM:DELay
double value = driver.Source.Pulm.Delay;
driver.Source.Pulm.Delay = 1.0;

Sets the pulse delay.

delay: float

ImpG50G1Kenum Impedance#
// SCPI: [SOURce<HW>]:PULM:IMPedance
ImpG50G1Kenum value = driver.Source.Pulm.Impedance;
driver.Source.Pulm.Impedance = ImpG50G1Kenum.G1K;

Sets the impedance for the external pulse modulation input.

impedance: G50 | G1K

PulsModeEnum Mode#
// SCPI: [SOURce<HW>]:PULM:MODE
PulsModeEnum value = driver.Source.Pulm.Mode;
driver.Source.Pulm.Mode = PulsModeEnum.DOUBle;

Selects the mode for the pulse modulation.

mode: SINGle | DOUBle SINGle Generates a single pulse. DOUBle Generates two pulses within one pulse period.

double Period#
// SCPI: [SOURce<HW>]:PULM:PERiod
double value = driver.Source.Pulm.Period;
driver.Source.Pulm.Period = 1.0;

Sets the period of the generated pulse, that means the repetition frequency of the internally generated modulation signal.

period: float The minimum value depends on the installed options R&S SMW-K22 or R&S SMW-K23 Range: 20E-9 to 100

NormalInvertedEnum Polarity#
// SCPI: [SOURce<HW>]:PULM:POLarity
NormalInvertedEnum value = driver.Source.Pulm.Polarity;
driver.Source.Pulm.Polarity = NormalInvertedEnum.INVerted;

Sets the polarity of the externally applied modulation signal.

polarity: NORMal | INVerted NORMal Suppresses the RF signal during the pulse pause. INVerted Suppresses the RF signal during the pulse.

SourceIntEnum Source#
// SCPI: [SOURce<HW>]:PULM:SOURce
SourceIntEnum value = driver.Source.Pulm.Source;
driver.Source.Pulm.Source = SourceIntEnum.EXTernal;

Selects between the internal (pulse generator) or an external pulse signal for the modulation.

source: INTernal | EXTernal

bool State#
// SCPI: [SOURce<HW>]:PULM:STATe
bool value = driver.Source.Pulm.State;
driver.Source.Pulm.State = false;

Activates pulse modulation.

state: 1 | ON | 0| OFF

PulsTransTypeEnum Ttype#
// SCPI: [SOURce<HW>]:PULM:TTYPe
PulsTransTypeEnum value = driver.Source.Pulm.Ttype;
driver.Source.Pulm.Ttype = PulsTransTypeEnum.FAST;

Sets the transition mode for the pulse signal.

source: SMOothed | FAST SMOothed flattens the slew rate, resulting in longer rise/fall times. FAST enables fast transitions with shortest rise and fall times.

double Width#
// SCPI: [SOURce<HW>]:PULM:WIDTh
double value = driver.Source.Pulm.Width;
driver.Source.Pulm.Width = 1.0;

Sets the width of the generated pulse, that means the pulse length. It must be at least 20ns less than the set pulse period.

width: float Range: 20E-9 to 100
