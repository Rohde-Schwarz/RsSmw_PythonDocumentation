Direct SCPI Members

bool Cmode#
// SCPI: [SOURce<HW>]:BB:WLNN:ANTenna:CMODe
bool value = driver.Source.Bb.Wlnn.Antenna.Cmode;

Queries the coupling state of transmit antennas. If enabled, the transmit antennas are coupled, i.e. they transmit the same frame blocks data.

cmode: 1 | ON | 0| OFF

WlannTxAntEnum Mode#
// SCPI: [SOURce<HW>]:BB:WLNN:ANTenna:MODE
WlannTxAntEnum value = driver.Source.Bb.Wlnn.Antenna.Mode;
driver.Source.Bb.Wlnn.Antenna.Mode = WlannTxAntEnum.A1;

The command selects the number of transmit antennas to be used.

mode: A1 | A2 | A3 | A4 | A5 | A6 | A7 | A8

WlannTxNumBbEnum Nobb#
// SCPI: [SOURce<HW>]:BB:WLNN:ANTenna:NOBB
WlannTxNumBbEnum value = driver.Source.Bb.Wlnn.Antenna.Nobb;

Queries the number of basebands required for the transmit antenna setup.

nobb: NBB1 | NBB2 | NBB4 | NBB3 | NBB8

CoordMapModeEnum System#
// SCPI: [SOURce<HW>]:BB:WLNN:ANTenna:SYSTem
CoordMapModeEnum value = driver.Source.Bb.Wlnn.Antenna.System;
driver.Source.Bb.Wlnn.Antenna.System = CoordMapModeEnum.CARTesian;

Selects the coordinate system of the transmission chain matrix.

system: CARTesian | CYLindrical
