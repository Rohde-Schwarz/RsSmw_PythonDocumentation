Direct SCPI Members

string Application#
// SCPI: SYSTem:COMMunicate:BB<HW>:QSFP:NETWork:APPLication
string value = driver.System.Communicate.Bb.Qsfp.Network.Application;

Queries a running application.

runningApp: string Returns the name of the running application. ExtSeq (10GbE) Extended sequencer at 10 Gbit Ethernet ARB Upload (10/40GbE) ARB Ethernet upload at 10 Gbit or 40 Gbit Ethernet ARB Stream (40GbE) ARB Ethernet streaming at 40 Gbit Ethernet

string MacAddress#
// SCPI: SYSTem:COMMunicate:BB<HW>:QSFP:NETWork:MACaddress
string value = driver.System.Communicate.Bb.Qsfp.Network.MacAddress;

Queries the MAC address of the network adapter. This is a password-protected function. Unlock the protection level 1 to access it, see method RsSmw.System.Protect.State.Set in the R&S SMW200A user manual.

macAddress: string

int Port#
// SCPI: SYSTem:COMMunicate:BB<HW>:QSFP:NETWork:PORT
int value = driver.System.Communicate.Bb.Qsfp.Network.Port;
driver.System.Communicate.Bb.Qsfp.Network.Port = 1;

Sets the port address used for network traffic.

portNumber: integer Range: 0 to 65536
