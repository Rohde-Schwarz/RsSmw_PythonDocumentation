Direct SCPI Members

class Date_Data

Structure for reading output parameters.

int Year

integer Range: 1980 to 9999

int Month

integer Range: 1 to 12

int Day

integer Range: 1 to 31

Date_Data Date#
// SCPI: [SOURce<HW>]:BB:GNSS:ADGeneration:NAVIC:TOAData:DATE
Date_Data value = driver.Source.Bb.Gnss.AdGeneration.Navic.ToaData.Date;

Enabled for UTC or GLONASS timebase (method RsSmw.Source.Bb.Gnss.AdGeneration.Gps.ToaData.Tbasis) . Queries the date for the assistance data in DMS format of the Gregorian calendar.

For return value, see the help for Date_Data structure arguments

TimeBasisEnum Tbasis#
// SCPI: [SOURce<HW>]:BB:GNSS:ADGeneration:NAVIC:TOAData:TBASis
TimeBasisEnum value = driver.Source.Bb.Gnss.AdGeneration.Navic.ToaData.Tbasis;

Queries the timebase for the time of assistance data parameters. Set the timebase via the following command: SOURce1:BB:GNSS:TIME:STARt:TBASis

timeBasis: UTC | GPS | GST | GLO | BDT | NAV

class Time_Data

Structure for reading output parameters.

int Hour

integer Range: 0 to 23

int Minute

integer Range: 0 to 59

double Second

float Range: 0 to 59.999

Time_Data Time#
// SCPI: [SOURce<HW>]:BB:GNSS:ADGeneration:NAVIC:TOAData:TIME
Time_Data value = driver.Source.Bb.Gnss.AdGeneration.Navic.ToaData.Time;

Queries the exact start time of the assistance data in UTC time format. Querying requires the UTC timebase or GLONASS timebase: SOURce1:BB:GNSS:ADGeneration:GPS:TOAData:TBASis UTC SOURce1:BB:GNSS:ADGeneration:GPS:TOAData:TBASis GLONASS See also method RsSmw.Source.Bb.Gnss.AdGeneration.Qzss.ToaData.Tbasis.

For return value, see the help for Time_Data structure arguments

int ToWeek#
// SCPI: [SOURce<HW>]:BB:GNSS:ADGeneration:NAVIC:TOAData:TOWeek
int value = driver.Source.Bb.Gnss.AdGeneration.Navic.ToaData.ToWeek;

Queries the Time of Week (TOW) of the assistance data for the related GNSS timebase. See also method RsSmw.Source.Bb.Gnss.AdGeneration.Qzss.ToaData.Tbasis.

tow: integer Range: -604800 to 604800

int Wnumber#
// SCPI: [SOURce<HW>]:BB:GNSS:ADGeneration:NAVIC:TOAData:WNUMber
int value = driver.Source.Bb.Gnss.AdGeneration.Navic.ToaData.Wnumber;

Queries the week number (WN) of the assistance data for the related GNSS timebase. See also method RsSmw.Source.Bb.Gnss.AdGeneration.Qzss.ToaData.Tbasis.

weekNumber: integer Range: 0 to 9999.0*53
