Source:Bb:Lora:Setting#

SCPI Commands

[SOURce<HW>]:BB:LORA:SETTing:CATalog
[SOURce<HW>]:BB:LORA:SETTing:DELete
[SOURce<HW>]:BB:LORA:SETTing:LOAD
[SOURce<HW>]:BB:LORA:SETTing:STORe

Direct SCPI Members

List<string>Catalog#
// SCPI: [SOURce<HW>]:BB:LORA:SETTing:CATalog
List<string> value = driver.Source.Bb.Lora.Setting.Catalog;

Queries the files with settings in the default directory. Listed are files with the file extension lora. Refer to “Accessing Files in the Default or Specified Directory” for general information on file handling in the default and in a specific directory.

catalog: filename1,filename2,… Returns a string of filenames separated by commas.

string Delete#
// SCPI: [SOURce<HW>]:BB:LORA:SETTing:DELete
string value = driver.Source.Bb.Lora.Setting.Delete;
driver.Source.Bb.Lora.Setting.Delete = "abc";

Deletes the selected file from the default or the specified directory. Deleated are files with extension lora. Refer to “Accessing Files in the Default or Specified Directory” for general information on file handling in the default and in a specific directory.

filename: “filename” Filename or complete file path; file extension can be omitted

string Load#
// SCPI: [SOURce<HW>]:BB:LORA:SETTing:LOAD
string value = driver.Source.Bb.Lora.Setting.Load;
driver.Source.Bb.Lora.Setting.Load = "abc";

Loads the selected file from the default or the specified directory. Loaded are files with extension lora. Refer to “Accessing Files in the Default or Specified Directory” for general information on file handling in the default and in a specific directory.

filename: “filename” Filename or complete file path; file extension can be omitted

string Store#
// SCPI: [SOURce<HW>]:BB:LORA:SETTing:STORe

driver.Source.Bb.Lora.Setting.Store = "abc";

Saves the current settings into the selected file; the file extension (lora) is assigned automatically. Refer to “Accessing Files in the Default or Specified Directory” for general information on file handling in the default and in a specific directory.

Filename: “filename” Filename or complete file path
