The command activates “mis-” use of the TPC field (Transmit Power Control) of the selected channel for controlling the channel powers of these channels of the specified base station. The bit pattern (see command method RsSmw.Source.Bb.W3Gpp.Bstation.Channel.Fdpch.Dpcch.Tpc.Data.Pattern.Set) of the TPC field of each channel is used to control the channel power. A “1” leads to an increase of channel powers, a “0” to a reduction of channel powers. Channel power is limited to the range 0 dB to -60 dB. The step width of the change is defined with the command method RsSmw.Source.Bb.W3Gpp.Bstation.Channel.Fdpch.Dpcch.Tpc.Pstep.Set.
