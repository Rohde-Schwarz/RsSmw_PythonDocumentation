Direct SCPI Members

double Dwell#
// SCPI: [SOURce<HW>]:SWEep:[FREQuency]:DWELl
double value = driver.Source.Sweep.Frequency.Dwell;
driver.Source.Sweep.Frequency.Dwell = 1.0;

Sets the dwell time for a frequency sweep step.

dwell: float Range: 0.001 to 100

AutoManStepEnum Mode#
// SCPI: [SOURce<HW>]:SWEep:[FREQuency]:MODE
AutoManStepEnum value = driver.Source.Sweep.Frequency.Mode;
driver.Source.Sweep.Frequency.Mode = AutoManStepEnum.AUTO;

Sets the cycle mode for the frequency sweep.

mode: AUTO | MANual | STEP AUTO Each trigger event triggers exactly one complete sweep. MANual The trigger system is not active. You can trigger every step individually by input of the frequencies with the command method RsSmw.Source.Frequency.Manual(). STEP Each trigger event triggers one sweep step. The frequency increases by the value entered with method RsSmw.Source.Sweep.Frequency.Step.Linear() (linear spacing) or method RsSmw.Source.Sweep.Frequency.Step.Logarithmic() (logarithmic spacing) .

int Points#
// SCPI: [SOURce<HW>]:SWEep:[FREQuency]:POINts
int value = driver.Source.Sweep.Frequency.Points;
driver.Source.Sweep.Frequency.Points = 1;

Sets the number of steps within the RF frequency sweep range. Two separate POINts values are used for linear or logarithmic sweep spacing. This command always affects the currently set sweep spacing that you can set via the following command: SOURce<hw>:SWEep:FREQuency:SPACing LINear | LOGarithmic

points: integer Range: 2 to Max

bool Retrace#
// SCPI: [SOURce<HW>]:SWEep:[FREQuency]:RETRace
bool value = driver.Source.Sweep.Frequency.Retrace;
driver.Source.Sweep.Frequency.Retrace = false;

Activates that the signal changes to the start frequency value while it is waiting for the next trigger event. You can enable this feature, when you are working with sawtooth shapes in sweep mode “Single” or “External Single”.

state: 1 | ON | 0| OFF

bool Running#
// SCPI: [SOURce<HW>]:SWEep:[FREQuency]:RUNNing
bool value = driver.Source.Sweep.Frequency.Running;

Queries the current sweep state.

state: 1 | ON | 0| OFF

SweCyclModeEnum Shape#

SweCyclModeEnum value = driver.Source.Sweep.Frequency.Shape;

Determines the waveform shape for a frequency sweep sequence.

shape: SAWTooth | TRIangle

SpacingEnum Spacing#
// SCPI: [SOURce<HW>]:SWEep:[FREQuency]:SPACing
SpacingEnum value = driver.Source.Sweep.Frequency.Spacing;
driver.Source.Sweep.Frequency.Spacing = SpacingEnum.LINear;

Selects the mode for the calculation of the frequency intervals, with which the current frequency at each step is increased or decreased. The keyword [:FREQuency] can be omitted; then the command is SCPI-compliant.

spacing: LINear | LOGarithmic LINear Sets a fixed frequency value as step width and adds it to the current frequency. The linear step width is entered in Hz, see method RsSmw.Source.Sweep.Frequency.Step.Linear(). LOGarithmic Sets a constant fraction of the current frequency as step width and adds it to the current frequency. The logarithmic step width is entered in %, see method RsSmw.Source.Sweep.Frequency.Step.Logarithmic().
