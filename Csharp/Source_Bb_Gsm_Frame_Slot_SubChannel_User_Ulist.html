This command deletes the selected file with user defined slot settings. The directory is set using command method RsSmw.MassMemory.CurrentDirectory. A path can also be specified, in which case the files in the specified directory are read. The file extension can be omitted. Only files with the file extension gsm_slu and gsm_hslu are deleted.

filename string

frameIx Repeated capability selector

slotNull Repeated capability selector

subChannel Repeated capability selector

userIx Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
