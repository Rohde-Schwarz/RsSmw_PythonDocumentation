Direct SCPI Members

List<string>Catalog#
// SCPI: [SOURce<HW>]:FSIMulator:CATalog
List<string> value = driver.Source.Fsimulator.Catalog;

Queries the files with settings in the default directory. Listed are files with the file extension fad. Refer to “Accessing Files in the Default or Specified Directory” for general information on file handling in the default and in a specific directory.

filenames: filename1,filename2,… Returns a string of filenames separated by commas.

FadTypeEnum Configuration#
// SCPI: [SOURce<HW>]:FSIMulator:CONFiguration
FadTypeEnum value = driver.Source.Fsimulator.Configuration;
driver.Source.Fsimulator.Configuration = FadTypeEnum.BIRThdeath;

Selects the fading configuration. To activate the selected fading configuration, use the command for switching the state.

configuration: STANdard | BIRThdeath | MDELay | TCInterferer | HSTRain | CDYNamic Defines the configuration: Standard delay, birth death propagation, moving propagation, two channel interferer, high-speed train and customized dynamic fading propagation.

bool value = driver.Source.Fsimulator.Cspeed;

Determines whether the same speed is set for all of the activated fading paths.

cspeed: 1 | ON | 0| OFF

void Delete ( string filename )#
// SCPI: [SOURce<HW>]:FSIMulator:DELETE
driver.Source.Fsimulator.Delete("abc");

Deletes the specified file containing a fading setting from the default directory. The default directory is set with the command method RsSmw.MassMemory.CurrentDirectory. A path can also be specified. Only files with the file ending fad are deleted. Note: This command is only valid with DELETE in the long form as DEL is used as short form of header keyword DELay.

filename string

FadPathFiltAllEnum Filter#
// SCPI: [SOURce<HW>]:FSIMulator:FILTer
FadPathFiltAllEnum value = driver.Source.Fsimulator.Filter;
driver.Source.Fsimulator.Filter = FadPathFiltAllEnum.ACTPlus;

Filters the path table for a subgroup of fading paths.

pathFilter: ALL | ACTPlus | ACTVe ALL Displays all paths in the path table. ACTPlus Displays all enabled paths and the first disabled path. ACTVe Displays all enabled paths.

void Load ( string filename )#
// SCPI: [SOURce<HW>]:FSIMulator:LOAD
driver.Source.Fsimulator.Load("abc");

Loads the selected file from the default or the specified directory. Loaded are files with extension fad. Refer to “Accessing Files in the Default or Specified Directory” for general information on file handling in the default and in a specific directory.

filename “filename” Filename or complete file path; file extension can be omitted.

void Preset ( )#
void PresetAndWait ( )#
void PresetAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:FSIMulator:PRESet
driver.Source.Fsimulator.Preset();
driver.Source.Fsimulator.PresetAndWait();
driver.Source.Fsimulator.PresetAndWait(1000);

Sets the default settings (*RST values) for fading simulation.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.

FadSignDestEnum Sdestination#
// SCPI: [SOURce<HW>]:FSIMulator:SDEStination
FadSignDestEnum value = driver.Source.Fsimulator.Sdestination;
driver.Source.Fsimulator.Sdestination = FadSignDestEnum.BB;

Defines the frequency to that the signal of the whole Fader block is dedicated.

sdestination: RF | BB RF The Doppler shift is calculated based on the actual RF frequency that is dynamically estimated. To query the estimated dedicated frequency, use the command method RsSmw.Source.Fsimulator.Frequency.Value(). To query the output connector, use the command method RsSmw.Source.Fsimulator.Frequency.Detect(). BB Set the fader frequency manually by the command method RsSmw.Source.Fsimulator.Frequency.Value().

string Store#
// SCPI: [SOURce<HW>]:FSIMulator:STORe

driver.Source.Fsimulator.Store = "abc";

Saves the current settings into the selected file; the file extension (fad) is assigned automatically. Refer to “Accessing Files in the Default or Specified Directory” for general information on file handling in the default and in a specific directory.

Filename: “filename” Filename or complete file path

FadTablePresetEnum Tpreset#

FadTablePresetEnum value = driver.Source.Fsimulator.Tpreset;
driver.Source.Fsimulator.Tpreset = FadTablePresetEnum.LOS;

Sets a predefined path configuration for the path table.

presetType: USER | LOS | NLOS USER Preset which offers full adjustment of all paths. LOS Preset which offers one line of sight path with Pure Doppler profile. NLOS Preset which offers one line of sight path with Pure Doppler profile and multiple non line of sight paths with Rayleigh profile.
