Direct SCPI Members

int Count#
// SCPI: [SOURce<HW>]:BB:C2K:PPARameter:TCHannel:COUNt
int value = driver.Source.Bb.C2K.Pparameter.Tchannel.Count;
driver.Source.Bb.C2K.Pparameter.Tchannel.Count = 1;

This command sets the number of activated traffic channels. The setting takes effect only after execution of command method RsSmw.Source.Bb.C2K.Pparameter.Execute.Set.

count: integer Range: 0 to 8

Cdma2KpredFramLenEnum Flength#
// SCPI: [SOURce<HW>]:BB:C2K:PPARameter:TCHannel:FLENgth
Cdma2KpredFramLenEnum value = driver.Source.Bb.C2K.Pparameter.Tchannel.Flength;
driver.Source.Bb.C2K.Pparameter.Tchannel.Flength = Cdma2KpredFramLenEnum._20;

The command activates/deactivates the fundamental channel. The set value is specific for the selected radio configuration. The setting takes effect only after execution of command method RsSmw.Source.Bb.C2K.Pparameter.Execute.Set. It is specific for the selected radio configuration. The frame length affects the data rates that are possible within a channel. Changing the frame length can lead to a change of data rate and this in turn can bring about a change of Walsh code.

flength: 20 | 40 | 80
