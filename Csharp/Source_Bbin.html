Direct SCPI Members

string Cdevice#
// SCPI: [SOURce<HW>]:BBIN:CDEVice
string value = driver.Source.Bbin.Cdevice;

Indicates the ID of an externally connected Rohde & Schwarz Instrument or Rohde & Schwarz device.

cdevice: string “None” - no device is connected.

double Cfactor#
// SCPI: [SOURce<HW>]:BBIN:CFACtor
double value = driver.Source.Bbin.Cfactor;
driver.Source.Bbin.Cfactor = 1.0;

No help available.

double Foffset#
// SCPI: [SOURce<HW>]:BBIN:FOFFset
double value = driver.Source.Bbin.Foffset;
driver.Source.Bbin.Foffset = 1.0;

Sets a frequency offset for the internal or external baseband signal. The offset affects the generated baseband signal.

foffset: float Range: depends on options , Unit: Hz E.g. -60 MHz to +60 MHz (R&S SMW-B10)

BbinModeDigitalEnum Mode#
// SCPI: [SOURce<HW>]:BBIN:MODE
BbinModeDigitalEnum value = driver.Source.Bbin.Mode;
driver.Source.Bbin.Mode = BbinModeDigitalEnum.DIGital;

Defines that a digital external signal is applied.

mode: DIGital

int Mperiod#
// SCPI: [SOURce<HW>]:BBIN:MPERiod
int value = driver.Source.Bbin.Mperiod;
driver.Source.Bbin.Mperiod = 1;

For method RsSmw.Source.Bbin.Digital.Source CODER1 | CODER2 Sets the recording duration for measuring the baseband input signal by executed method RsSmw.Source.Bbin.Alevel.Execute.Set.

mperiod: integer Range: 1 to 32, Unit: s

double Pgain#
// SCPI: [SOURce<HW>]:BBIN:PGAin
double value = driver.Source.Bbin.Pgain;
driver.Source.Bbin.Pgain = 1.0;

Sets the relative gain for the internal or external baseband signal compared with the signals of the other baseband sources.

pgain: float Range: -50 to 50, Unit: dB

double Poffset#
// SCPI: [SOURce<HW>]:BBIN:POFFset
double value = driver.Source.Bbin.Poffset;
driver.Source.Bbin.Poffset = 1.0;

Sets the relative phase offset for the external baseband signal.

poffset: float Range: -999.99 to 999.99, Unit: DEG

PathUniCodBbinEnum Route#
// SCPI: [SOURce<HW>]:BBIN:ROUTe
PathUniCodBbinEnum value = driver.Source.Bbin.Route;
driver.Source.Bbin.Route = PathUniCodBbinEnum.A;

Selects the signal route for the internal/external baseband signal. The internal and external signals are summed, if necessary.

route: A | B| AB

bool State#
// SCPI: [SOURce<HW>]:BBIN:STATe
bool value = driver.Source.Bbin.State;
driver.Source.Bbin.State = false;

Enables feeding of an external digital signal into the signal path.

state: 1 | ON | 0| OFF
