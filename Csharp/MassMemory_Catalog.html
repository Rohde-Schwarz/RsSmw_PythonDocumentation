MassMemory:Catalog#

SCPI Commands

MMEMory:CATalog

Cloning the Group

// Create a clone of the original group, that exists independently
var catalog2 = driver.MassMemory.Catalog.Clone();

Direct SCPI Members

string Value#
// SCPI: MMEMory:CATalog
string value = driver.MassMemory.Catalog.Value;

Returns the content of a particular directory.

catalog: string String parameter to specify the directory. If you leave out the path, the command returns the contents of the directory selected with method RsSmw.MassMemory.CurrentDirectory(). The path can be relative or absolute.
