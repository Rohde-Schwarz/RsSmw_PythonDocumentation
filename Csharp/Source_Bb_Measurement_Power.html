void Abort ( )#
void AbortAndWait ( )#
void AbortAndWait ( int opcTimeoutMs )
// SCPI: [SOURce]:BB:MEASurement:POWer:ABORt
driver.Source.Bb.Measurement.Power.Abort();
driver.Source.Bb.Measurement.Power.AbortAndWait();
driver.Source.Bb.Measurement.Power.AbortAndWait(1000);

Stops the current measurement.

AbortAndWait is the same as Abort, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
