Direct SCPI Members

double Clock
// SCPI: [SOURce<HW>]:BB:ARBitrary:MCARrier:CLOCk
double value = driver.Source.Bb.Arbitrary.Mcarrier.Clock;

Queries the resulting sample rate at which the multi-carrier waveform is output by the arbitrary waveform generator. The output clock rate depends on the number of carriers, carrier spacing, and input sample rate of the leftmost or rightmost carriers.

clock: float Range: 400 to Max

string Ofile
// SCPI: [SOURce<HW>]:BB:ARBitrary:MCARrier:OFILe
string value = driver.Source.Bb.Arbitrary.Mcarrier.Ofile;
driver.Source.Bb.Arbitrary.Mcarrier.Ofile = "abc";

Sets the output filename for the multicarrier waveform (file extension wv) . This filename is required to calculate the waveform with the commands method RsSmw.Source.Bb.Arbitrary.Mcarrier.Cload.Set or method RsSmw.Source.Bb.Arbitrary.Mcarrier.Create.Set.

ofile: string

void Preset ( )
void PresetAndWait ( )
void PresetAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:BB:ARBitrary:MCARrier:PRESet
driver.Source.Bb.Arbitrary.Mcarrier.Preset();
driver.Source.Bb.Arbitrary.Mcarrier.PresetAndWait();
driver.Source.Bb.Arbitrary.Mcarrier.PresetAndWait(1000);

Sets all the multicarrier parameters to their default values.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.

int Samples
// SCPI: [SOURce<HW>]:BB:ARBitrary:MCARrier:SAMPles

Queries the resulting file size.

samples: integer Range: 0 to INT_MAX, Unit: samples
