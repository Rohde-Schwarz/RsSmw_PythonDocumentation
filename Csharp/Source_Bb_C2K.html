Direct SCPI Members

LinkDirEnum Link#
// SCPI: [SOURce<HW>]:BB:C2K:LINK
LinkDirEnum value = driver.Source.Bb.C2K.Link;
driver.Source.Bb.C2K.Link = LinkDirEnum.DOWN;

The command defines the transmission direction. The signal either corresponds to that of a base station (FORWard | DOWN) or that of a mobile station (REVerse | UP) .

link: DOWN | UP | FORWard | REVerse

void Preset ( )#
void PresetAndWait ( )#
void PresetAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:BB:C2K:PRESet
driver.Source.Bb.C2K.Preset();
driver.Source.Bb.C2K.PresetAndWait();
driver.Source.Bb.C2K.PresetAndWait(1000);

Sets the parameters of the digital standard to their default values (*RST values specified for the commands) . Not affected is the state set with the command SOURce<hw>:BB:C2K:STATe.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.

int Slength#
// SCPI: [SOURce<HW>]:BB:C2K:SLENgth
int value = driver.Source.Bb.C2K.Slength;
driver.Source.Bb.C2K.Slength = 1;

Sets the sequence length of the arbitrary waveform component of the CDMA2000 signal in the number of frames.

slength: integer Range: 1 to max

bool State#
// SCPI: [SOURce<HW>]:BB:C2K:STATe
bool value = driver.Source.Bb.C2K.State;
driver.Source.Bb.C2K.State = false;

Activates the standard and deactivates all the other digital standards and digital modulation modes in the same path.

state: 1 | ON | 0| OFF

string Version#
// SCPI: [SOURce]:BB:C2K:VERSion
string value = driver.Source.Bb.C2K.Version;

The command queries the version of the CDMA standard underlying the definitions.

version: string
