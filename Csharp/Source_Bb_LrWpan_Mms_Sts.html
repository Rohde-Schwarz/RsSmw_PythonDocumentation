Direct SCPI Members

string Cpart#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:MMS:STS:CPARt
string value = driver.Source.Bb.LrWpan.Mms.Sts.Cpart;
driver.Source.Bb.LrWpan.Mms.Sts.Cpart = "rawAbc";

Sets the counter part of the V value. The value is a 32-bit value in hexadecimal representation.

counterPart: integer

HrpUwbStsDeltaLenEnum Dlen#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:MMS:STS:DLEN
HrpUwbStsDeltaLenEnum value = driver.Source.Bb.LrWpan.Mms.Sts.Dlen;

Queries the delta length of the scrambled timestamp sequence (STS) . The delta length depends on the HRP UWB mode.

deltaLength: DL_4 | DL_8

bool Dls#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:MMS:STS:DLS
bool value = driver.Source.Bb.LrWpan.Mms.Sts.Dls;
driver.Source.Bb.LrWpan.Mms.Sts.Dls = false;

Activates the STS source. If activated, you can select an STS data list from a designated folder to import a user defined STS sequence.

stsDatalist: 1 | ON | 0| OFF

string Key#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:MMS:STS:KEY
string value = driver.Source.Bb.LrWpan.Mms.Sts.Key;
driver.Source.Bb.LrWpan.Mms.Sts.Key = "rawAbc";

Sets the key value of the scrambled timestamp sequence (STS) . The value is a 128-bit value in hexadecimal representation.

key: integer

string Upart#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:MMS:STS:UPARt
string value = driver.Source.Bb.LrWpan.Mms.Sts.Upart;
driver.Source.Bb.LrWpan.Mms.Sts.Upart = "rawAbc";

Sets the upper part of the V value. The value is a 96-bit value in hexadecimal representation.

upperPart: integer
