Direct SCPI Members

bool Busy#

No help available.

string MacAddress#
// SCPI: SYSTem:COMMunicate:BB<HW>:NETWork:MACaddress
string value = driver.System.Communicate.Bb.Network.MacAddress;
driver.System.Communicate.Bb.Network.MacAddress = "abc";

Queries the MAC address of the network adapter. This is a password-protected function. Unlock the protection level 1 to access it, see method RsSmw.System.Protect.State.Set in the R&S SMW200A user manual.

macAddress: string

int Port#
// SCPI: SYSTem:COMMunicate:BB<HW>:NETWork:PORT
int value = driver.System.Communicate.Bb.Network.Port;
driver.System.Communicate.Bb.Network.Port = 1;

Sets the port address use for network traffic.

port: integer Range: 0 to 65536

NetProtocolEnum Protocol#
// SCPI: SYSTem:COMMunicate:BB<HW>:NETWork:PROTocol
NetProtocolEnum value = driver.System.Communicate.Bb.Network.Protocol;
driver.System.Communicate.Bb.Network.Protocol = NetProtocolEnum.TCP;

Selects the communication protocol for the network traffic.

protocol: UDP | TCP

bool Status#
// SCPI: SYSTem:COMMunicate:BB<HW>:NETWork:STATus
bool value = driver.System.Communicate.Bb.Network.Status;

Queries the network configuration state.

state: 1 | ON | 0| OFF
