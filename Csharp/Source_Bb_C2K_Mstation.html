Direct SCPI Members

void Preset ( )

// SCPI: [SOURce<HW>]:BB:C2K:MSTation:PRESet
driver.Source.Bb.C2K.Mstation.Preset();
driver.Source.Bb.C2K.Mstation.PresetAndWait();
driver.Source.Bb.C2K.Mstation.PresetAndWait(1000);

A standardized default for all the mobile stations (*RST values specified for the commands) . See “Reset All Mobile Stations” for an overview.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
