Source:Pm:Deviation#

SCPI Commands

[SOURce<HW>]:PM:DEViation:MODE
[SOURce<HW>]:PM:DEViation:SUM
[SOURce]:PM<CH>:[DEViation]

Direct SCPI Members

ModulationDevModeEnum Mode#
// SCPI: [SOURce<HW>]:PM:DEViation:MODE
ModulationDevModeEnum value = driver.Source.Pm.Deviation.Mode;
driver.Source.Pm.Deviation.Mode = ModulationDevModeEnum.RATio;

Selects the coupling mode. The coupling mode parameter also determines the mode for fixing the total deviation.

pmDevMode: UNCoupled | TOTal | RATio UNCoupled Does not couple the LF signals. The deviation values of both paths are independent. TOTal Couples the deviation of both paths. RATio Couples the deviation ratio of both paths

double Sum#
// SCPI: [SOURce<HW>]:PM:DEViation:SUM
double value = driver.Source.Pm.Deviation.Sum;
driver.Source.Pm.Deviation.Sum = 1.0;

Sets the total deviation of the LF signal when using combined signal sources in phase modulation.

pmDevSum: float Range: 0 to max

Sets the modulation deviation of the phase modulation in RAD.

deviation float The maximal deviation depends on the RF frequency and the selected modulation mode (see the specifications document) . Range: 0 to max, Unit: RAD

generatorIx Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
