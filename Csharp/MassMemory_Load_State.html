MassMemory:Load:State#

SCPI Commands

MMEMory:LOAD:STATe

Direct SCPI Members

void Set ( int dataSet, string sourceFile )#
// SCPI: MMEMory:LOAD:STATe
driver.MassMemory.Load.State.Set(1, "abc");

Loads the specified file stored under the specified name in an internal memory. After the file has been loaded, the instrument setting must be activated using an *RCL command.

dataSet Determines to the specific number to be used with the *RCL command, e.g. *RCL 4.

sourceFile Filename with file extension savrcltxt.
