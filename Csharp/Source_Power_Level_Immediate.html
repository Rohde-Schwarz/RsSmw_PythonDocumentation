Source:Power:Level:Immediate#

SCPI Commands

[SOURce<HW>]:POWer:[LEVel]:[IMMediate]:OFFSet
[SOURce<HW>]:POWer:[LEVel]:[IMMediate]:RCL
[SOURce<HW>]:POWer:[LEVel]:[IMMediate]:REFLevel
[SOURce<HW>]:POWer:[LEVel]:[IMMediate]:[AMPLitude]

Direct SCPI Members

double Offset#
// SCPI: [SOURce<HW>]:POWer:[LEVel]:[IMMediate]:OFFSet
double value = driver.Source.Power.Level.Immediate.Offset;
driver.Source.Power.Level.Immediate.Offset = 1.0;

Sets the level offset of a downstream instrument. The level at the RF output is not changed. To query the resulting level, as it is at the output of the downstream instrument, use the command method RsSmw.Source.Power.Level.Immediate.Amplitude. See “Displayed RF frequency and level values with downstream instruments”. Note: The level offset also affects the RF level sweep.

offset: float Range: -100 to 100 , Unit: dB Level offset is always expreced in dB; linear units (V, W, etc.) are not supported

InclExclEnum Recall#
// SCPI: [SOURce<HW>]:POWer:[LEVel]:[IMMediate]:RCL
InclExclEnum value = driver.Source.Power.Level.Immediate.Recall;
driver.Source.Power.Level.Immediate.Recall = InclExclEnum.EXCLude;

Determines whether the current level is retained or if the stored level setting is adopted when an instrument configuration is loaded. The setting is valid for both paths. If a suffix is specified, it is ignored.

rcl: INCLude | EXCLude INCLude Takes the current level when an instrument configuration is loaded. EXCLude Retains the current level when an instrument configuration is loaded.

double RefLevel#
// SCPI: [SOURce<HW>]:POWer:[LEVel]:[IMMediate]:REFLevel
double value = driver.Source.Power.Level.Immediate.RefLevel;
driver.Source.Power.Level.Immediate.RefLevel = 1.0;

Queries the reference level of the user correction. The reference level is the sum of the amplitude and the level offset, set with the commands method RsSmw.Source.Power.Power method RsSmw.Source.Power.Level.Immediate.Offset.

referenceLevel: float Range: -245 to 120

double Amplitude#
// SCPI: [SOURce<HW>]:POWer:[LEVel]:[IMMediate]:[AMPLitude]
double value = driver.Source.Power.Level.Immediate.Amplitude;
driver.Source.Power.Level.Immediate.Amplitude = 1.0;

Sets the RF level applied to the DUT. To activate the RF output use command method RsSmw.Output.State.Value (“RF On”/”RF Off”) . The following applies POWer = RF output level + OFFSet, where:

  • POWer is the values set with method RsSmw.Source.Power.Level.Immediate.Amplitude

  • RF output level is set with method RsSmw.Source.Power.Power

  • OFFSet is set with method RsSmw.Source.Power.Level.Immediate.Offset

amplitude: float The following settings influence the value range: OFFSet set with the command method RsSmw.Source.Power.Level.Immediate.Offset() Numerical value Sets the level UP | DOWN Varies the level step by step. The level is increased or decreased by the value set with the command method RsSmw.Source.Power.Step.Increment(). Range: (Level_min + OFFSet) to (Level_max + OFFStet) , Unit: dBm
