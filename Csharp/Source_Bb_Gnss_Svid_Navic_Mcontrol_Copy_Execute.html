Applies the configuration of the current satellite (SVID<ch>:<GNSS system>) to the satellite defined with the command method RsSmw.Source.Bb.Gnss.Svid.Gps.Mcontrol.Copy.Svid.Set. Both SV IDs belong to the same GNSS system.

satelliteSvid Repeated capability selector

SetAndWait is the same as Set, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
