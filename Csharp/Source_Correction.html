Source:Correction#

SCPI Commands

[SOURce<HW>]:CORRection:VALue
[SOURce<HW>]:CORRection:[STATe]

Cloning the Group

// Create a clone of the original group, that exists independently
var correction2 = driver.Source.Correction.Clone();

Direct SCPI Members

double Value#
// SCPI: [SOURce<HW>]:CORRection:VALue
double value = driver.Source.Correction.Value;

Queries the current value for user correction.

value: float Range: -100 to 100

bool State#
// SCPI: [SOURce<HW>]:CORRection:[STATe]
bool value = driver.Source.Correction.State;
driver.Source.Correction.State = false;

Activates user correction with the currently selected table.

state: 1 | ON | 0| OFF
