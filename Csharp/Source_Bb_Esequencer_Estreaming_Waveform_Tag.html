Source:Bb:Esequencer:Estreaming:Waveform:Tag#

SCPI Commands

[SOURce<HW>]:BB:ESEQuencer:ESTReaming:WAVeform:TAG

Direct SCPI Members

string Get ( string tagName )#
// SCPI: [SOURce<HW>]:BB:ESEQuencer:ESTReaming:WAVeform:TAG
string value = driver.Source.Bb.Esequencer.Estreaming.Waveform.Tag.Get("abc");

Queries the waveform tags defined in the ODW. Query results are returned in a comma-separated list. Listed are pairs “<TagName>”<”<TagValue>”> for each tag. Listed are tags with the following names:

  • CLOCK

  • LEVEL OFFS

  • Request buffer size

tagValue: string Value of the waveform tag.

tagName string Name of the waveform tag.
