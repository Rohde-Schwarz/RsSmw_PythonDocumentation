Selects the modulation source for frequency modulation.

source INTernal | EXTernal | LF1 | LF2 | NOISe | EXT1 | EXT2 | INTB LF1 | LF2 Uses an internally generated LF signal. INTernal = LF1 Works like LF1 EXTernal Works like EXT1 EXT1 | EXT2 Uses an externally supplied LF signal. NOISe Uses the internally generated noise signal. INTB Uses the internal baseband signal.

generatorIx Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
