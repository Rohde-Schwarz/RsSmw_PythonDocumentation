Defines the mapping of the antenna ports to the physical antennas:

  • Per user (1 to 4) ,

  • Per layer (1 to 2) ,

  • Per antenna port (8 to 15 and 60, 61, 107, 109) , and

  • Per row selecting baseband (0 to 7) .

The command specifies real / magnitude part.

antPortMapData float The REAL (magnitude) and IMAGinary (phase) values are interdependent. Their value ranges change depending on each other and so that the resulting complex value is as follows: REAL+jIMAGinary <= 1 Otherwise, the values are normalized to magnitude = 1. Range: -1 to 360

userIx Repeated capability selector

layerNull Repeated capability selector

antennaPortNull Repeated capability selector

row Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
