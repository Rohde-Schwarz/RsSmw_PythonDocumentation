Direct SCPI Members

ParameterSetModeEnum Mode#
// SCPI: [SOURce<HW>]:LIST:DWELl:MODE
ParameterSetModeEnum value = driver.Source.List.Dwell.Mode;
driver.Source.List.Dwell.Mode = ParameterSetModeEnum.GLOBal;

Selects the dwell time mode.

dwellMode: LIST | GLOBal LIST Uses the dwell time, specified in the data table for each value pair individually. GLOBal Uses a constant dwell time, set with command method RsSmw.Source.List.Dwell.Value().

double Value#
// SCPI: [SOURce<HW>]:LIST:DWELl
double value = driver.Source.List.Dwell.Value;
driver.Source.List.Dwell.Value = 1.0;

Sets the global dwell time. The instrument generates the signal with the frequency / power value pairs of each list entry for that particular period. See also “Significant parameters and functions”.

dwell: float Range: 0.5E-3 to 100
