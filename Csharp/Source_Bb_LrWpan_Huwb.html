Direct SCPI Members

bool Srf#
// SCPI: [SOURce<HW>]:BB:LRWPan:HUWB:SRF
bool value = driver.Source.Bb.LrWpan.Huwb.Srf;
driver.Source.Bb.LrWpan.Huwb.Srf = false;

Sets the RF output frequency automatically to the value of the channel center frequency according to the selected channel number. You can still adjust the RF frequency afterwards.

setRf: 1 | ON | 0| OFF

HrpUwbActSegmentLengthEnum Asl#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:HUWB:ASL
HrpUwbActSegmentLengthEnum value = driver.Source.Bb.LrWpan.Huwb.Asl;
driver.Source.Bb.LrWpan.Huwb.Asl = HrpUwbActSegmentLengthEnum.ASL_1024;

Sets the active segment length.

actSegLength: ASL_16 | ASL_32 | ASL_64 | ASL_128 | ASL_256 | ASL_512 | ASL_1024 | ASL_2048

HrpUwbActSegmentNumEnum Asn#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:HUWB:ASN
HrpUwbActSegmentNumEnum value = driver.Source.Bb.LrWpan.Huwb.Asn;
driver.Source.Bb.LrWpan.Huwb.Asn = HrpUwbActSegmentNumEnum.ASN_1;

Requires [:SOURce<hw>]:BB:LRWPan | HUWB:STD BPRF | HPRF | EHPRF | SENS. Sets the number of active segments.

acgSegNumber: ASN_1 | ASN_2 | ASN_3 | ASN_4

double Bandwidth#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:HUWB:BWIDth
double value = driver.Source.Bb.LrWpan.Huwb.Bandwidth;

Queries the channel bandwidth. The bandwidth depends on the channel number.

HrpUwbConvConsLenEnum Cccl#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:HUWB:CCCL
HrpUwbConvConsLenEnum value = driver.Source.Bb.LrWpan.Huwb.Cccl;
driver.Source.Bb.LrWpan.Huwb.Cccl = HrpUwbConvConsLenEnum.CL3;

Sets the constraint length of the convolutional code.

cccl: CL3 | CL7

int Cnumber#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:HUWB:CNUMber
int value = driver.Source.Bb.LrWpan.Huwb.Cnumber;
driver.Source.Bb.LrWpan.Huwb.Cnumber = 1;

Sets the channel number that is a 4-bit value in decimal representation. The channel number determines the bandwidth and the code index.

channelNumber: integer Range: 0 to 15

bool F2ms#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:HUWB:F2MS
bool value = driver.Source.Bb.LrWpan.Huwb.F2ms;
driver.Source.Bb.LrWpan.Huwb.F2ms = false;

Sets the frame length of a generated waveform shorter than 2 ms to a fixed value of 2 ms. If activated, the idle interval is set to 0.0 us by default. Generated waveforms longer than 2 ms remain unaffected.

fixed2MsFrame: 1 | ON | 0| OFF

double Iinterval#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:HUWB:IINTerval
double value = driver.Source.Bb.LrWpan.Huwb.Iinterval;
driver.Source.Bb.LrWpan.Huwb.Iinterval = 1.0;

Sets the time of the interval separating two frames.

iinterval: float Range: 0 to 1000000, Unit: us

ZigbeeOperatingBandEnum Oband#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:HUWB:OBANd
ZigbeeOperatingBandEnum value = driver.Source.Bb.LrWpan.Huwb.Oband;
driver.Source.Bb.LrWpan.Huwb.Oband = ZigbeeOperatingBandEnum.OB2380;

Requires R&S SMW-K180. Sets the operating band for 802.15.4 with O-QPSK modulation.

operBand: OB780 | OB868 | OB915 | OB2380 | OB2450 | OB5800 | OB6200
