string Value#
// SCPI: SYSTem:SPECification:VERSion
string value = driver.System.Specification.Version.Value;
driver.System.Specification.Version.Value = "abc";

Selects a data sheet version from the data sheets saved on the instrument. Further queries regarding the data sheet parameters (<Id>) and their values refer to the selected data sheet. To query the list of data sheet versions, use the command method RsSmw.System.Specification.Version.Catalog.

version: string
