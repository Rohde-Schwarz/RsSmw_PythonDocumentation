Direct SCPI Members

HrpUwbCfgIndexEnum Cindex#
// SCPI: [SOURce<HW>]:BB:LRWPan:OQPSk:CINDex
HrpUwbCfgIndexEnum value = driver.Source.Bb.LrWpan.Oqpsk.Cindex;

Requires [:SOURce<hw>]:BB[:LRWPan]:HUWB | OQPSk:OBANd OB5800 | OB6200. Sets the configuration index, which determines for example the SYNC length and SFD length for symbol-to-chip mapping in the selected operating band.

configIndex: CI1 | CI2 | CI3 | CI4 | CI5 | CI6 | CI7 | CI8

double Bandwidth#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:OQPSk:BWIDth
double value = driver.Source.Bb.LrWpan.Oqpsk.Bandwidth;

Queries the channel bandwidth. The bandwidth depends on the channel number.

HrpUwbConvConsLenEnum Cccl#

Sets the constraint length of the convolutional code.

cccl: CL3 | CL7

int Cnumber#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:OQPSk:CNUMber
int value = driver.Source.Bb.LrWpan.Oqpsk.Cnumber;
driver.Source.Bb.LrWpan.Oqpsk.Cnumber = 1;

Sets the channel number that is a 4-bit value in decimal representation. The channel number determines the bandwidth and the code index.

channelNumber: integer Range: 0 to 15

bool F2ms#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:OQPSk:F2MS
bool value = driver.Source.Bb.LrWpan.Oqpsk.F2ms;
driver.Source.Bb.LrWpan.Oqpsk.F2ms = false;

Sets the frame length of a generated waveform shorter than 2 ms to a fixed value of 2 ms. If activated, the idle interval is set to 0.0 us by default. Generated waveforms longer than 2 ms remain unaffected.

fixed2MsFrame: 1 | ON | 0| OFF

double Iinterval#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:OQPSk:IINTerval
double value = driver.Source.Bb.LrWpan.Oqpsk.Iinterval;
driver.Source.Bb.LrWpan.Oqpsk.Iinterval = 1.0;

Sets the time of the interval separating two frames.

iinterval: float Range: 0 to 1000000, Unit: us
