Direct SCPI Members

LinkDirEnum Link#
// SCPI: [SOURce<HW>]:BB:TDSCdma:LINK
LinkDirEnum value = driver.Source.Bb.Tdscdma.Link;
driver.Source.Bb.Tdscdma.Link = LinkDirEnum.DOWN;

Defines the transmission direction.

link: FORWard | DOWN | REVerse | UP

void Preset ( )#
void PresetAndWait ( )#
void PresetAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:BB:TDSCdma:PRESet
driver.Source.Bb.Tdscdma.Preset();
driver.Source.Bb.Tdscdma.PresetAndWait();
driver.Source.Bb.Tdscdma.PresetAndWait(1000);

Sets the parameters of the digital standard to their default values (*RST values specified for the commands) . Not affected is the state set with the command SOURce<hw>:BB:TDSCdma:STATe.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.

void Reset ( )#
void ResetAndWait ( )#
void ResetAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:BB:TDSCdma:RESet
driver.Source.Bb.Tdscdma.Reset();
driver.Source.Bb.Tdscdma.ResetAndWait();
driver.Source.Bb.Tdscdma.ResetAndWait(1000);

Resets all cells to the predefined settings. The reset applies to the selected link direction. An overview is provided by table in “Set to Default”.

ResetAndWait is the same as Reset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.

int Slength#
// SCPI: [SOURce<HW>]:BB:TDSCdma:SLENgth
int value = driver.Source.Bb.Tdscdma.Slength;
driver.Source.Bb.Tdscdma.Slength = 1;

Sets the sequence length of the arbitrary waveform component of the TD-SCDMA signal in the number of frames. This component is calculated in advance and output in the arbitrary waveform generator. It is added to the realtime signal components.

slength: integer Range: 1 to 5000

bool State#
// SCPI: [SOURce<HW>]:BB:TDSCdma:STATe
bool value = driver.Source.Bb.Tdscdma.State;
driver.Source.Bb.Tdscdma.State = false;

Activates the standard and deactivates all the other digital standards and digital modulation modes in the same path.

state: 1 | ON | 0| OFF

Queries the version of the TD-SCDMA standard underlying the definitions.

version: string
