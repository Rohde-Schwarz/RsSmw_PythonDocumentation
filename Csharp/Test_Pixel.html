Test:Pixel#

SCPI Commands

TEST:PIXel:COLor
TEST:PIXel:GRADient
TEST<HW>:PIXel:POINtsize
TEST:PIXel:RGBA
TEST:PIXel:TEXT
TEST:PIXel:WINDow

Direct SCPI Members

PixelTestPredefinedEnum Color#
// SCPI: TEST:PIXel:COLor

driver.Test.Pixel.Color = PixelTestPredefinedEnum.AUTO;

Selects the color of the screen. “AUTO” switches from one color to the next in tme intervals of approximately 3 s per color.

PixTestColor: RED | BLUE | WHITe | GREen | AUTO | GR25 | GR50 | GR75 | BLACk

bool Gradient#
// SCPI: TEST:PIXel:GRADient
bool value = driver.Test.Pixel.Gradient;
driver.Test.Pixel.Gradient = false;

Activates the gradient for display screen test.

pixTestGradStat: 1 | ON | 0| OFF

int PointSize#
// SCPI: TEST<HW>:PIXel:POINtsize
int value = driver.Test.Pixel.PointSize;
driver.Test.Pixel.PointSize = 1;

Sets the point size of the test text.

pixTestGradStat: integer Range: 0 to 999

List<int>Rgba#
// SCPI: TEST:PIXel:RGBA
List<int> value = driver.Test.Pixel.Rgba;
driver.Test.Pixel.Rgba = new List<int> { 1, 2, 3 };

Sets a specific RGBA color for the screen.

bool Text#
// SCPI: TEST:PIXel:TEXT
bool value = driver.Test.Pixel.Text;
driver.Test.Pixel.Text = false;

Activats the test text mode.

pixTestGradStat: 1 | ON | 0| OFF

bool Window#
// SCPI: TEST:PIXel:WINDow

driver.Test.Pixel.Window = false;

Activates the check display screen.

PixTestWindow: 1 | ON | 0| OFF
