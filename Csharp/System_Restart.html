System:Restart#

SCPI Commands

SYSTem:RESTart

Direct SCPI Members

void Set ( )#
void SetAndWait ( )#
void SetAndWait ( int opcTimeoutMs )
// SCPI: SYSTem:RESTart
driver.System.Restart.Set();
driver.System.Restart.SetAndWait();
driver.System.Restart.SetAndWait(1000);

Restarts the instrument without restarting the operating system.

SetAndWait is the same as Set, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
