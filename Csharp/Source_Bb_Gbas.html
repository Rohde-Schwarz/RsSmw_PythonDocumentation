void Preset ( )#
void PresetAndWait ( )#
void PresetAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:BB:GBAS:PRESet
driver.Source.Bb.Gbas.Preset();
driver.Source.Bb.Gbas.PresetAndWait();
driver.Source.Bb.Gbas.PresetAndWait(1000);

Sets the parameters of the digital standard to their default values (*RST values specified for the commands) . Not affected is the state set with the command SOURce<hw>:BB:GBAS:STATe.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
