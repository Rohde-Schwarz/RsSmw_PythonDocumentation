Direct SCPI Members

RegTrigModeEnum Mode#
// SCPI: [SOURce<HW>]:REGenerator:RESTart:MODE
RegTrigModeEnum value = driver.Source.Regenerator.Restart.Mode;
driver.Source.Regenerator.Restart.Mode = RegTrigModeEnum.AAUTo;

Selects the event which leads to a restart of the REG simulation.

mode: AUTO | AAUTo AUTO The signal generation starts after the REG is enabled. The signal is generated continuously; all configured objects are simulated. AAUT Simulation starts upon trigger event (method RsSmw.Source.Regenerator.Restart.Execute.Set()) . Then the signal is generated continuously; all configured objects are simulated.

TrigRunModeEnum Rmode#
// SCPI: [SOURce<HW>]:REGenerator:RESTart:RMODe
TrigRunModeEnum value = driver.Source.Regenerator.Restart.Rmode;

Queries the status of signal generation for all trigger modes.

rmode: STOP | RUN

TrigSourRegEnum Source#
// SCPI: [SOURce<HW>]:REGenerator:RESTart:SOURce
TrigSourRegEnum value = driver.Source.Regenerator.Restart.Source;
driver.Source.Regenerator.Restart.Source = TrigSourRegEnum.ERRTA;

Selects the trigger signal source and determines the way the triggering is executed.

source: INTernal | ERRTA | ERRTB INTernal Internal triggering by the command method RsSmw.Source.Regenerator.Restart.Execute.Set(). ERRTA | ERRTB External trigger signal via one of the external global trigger connectors. See method RsSmw.Source.Input.User.Signal.Set().

double StAttenuation#
// SCPI: [SOURce<HW>]:REGenerator:RESTart:STATtenuation
double value = driver.Source.Regenerator.Restart.StAttenuation;
driver.Source.Regenerator.Restart.StAttenuation = 1.0;

If method RsSmw.Source.Regenerator.Restart.Mode AAUT, sets the attenuation applied on the output signal during the time the signal generation is stopped.

stopTimeAtt: float Range: 0 to 60
