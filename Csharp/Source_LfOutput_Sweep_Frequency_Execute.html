SCPI Commands

Direct SCPI Members

// SCPI: [SOURce<HW>]:LFOutput:SWEep:[FREQuency]:EXECute
driver.Source.LfOutput.Sweep.Frequency.Execute.Set();
driver.Source.LfOutput.Sweep.Frequency.Execute.SetAndWait();
driver.Source.LfOutput.Sweep.Frequency.Execute.SetAndWait(1000);

Immediately starts an LF sweep. method RsSmw.Source.LfOutput.Sweep.Frequency.Mode determines which sweep is executed, e.g. SOURce:LFOutput:SWEep:FREQuency:MODE STEP.

SetAndWait is the same as Set, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
