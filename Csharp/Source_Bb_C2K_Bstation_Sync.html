Direct SCPI Members

int Cnumber#
// SCPI: [SOURce<HW>]:BB:C2K:BSTation:SYNC:CNUMber
int value = driver.Source.Bb.C2K.Bstation.Sync.Cnumber;
driver.Source.Bb.C2K.Bstation.Sync.Cnumber = 1;

Sets the CDMA Channel Number which corresponds to the RF.

cnumber: integer Range: 0 to 2047

string LcState#
// SCPI: [SOURce<HW>]:BB:C2K:BSTation:SYNC:LCSTate
string value = driver.Source.Bb.C2K.Bstation.Sync.LcState;
driver.Source.Bb.C2K.Bstation.Sync.LcState = "rawAbc";

Defines the long code state in hexadecimal format.

lcState: 42 bit Range: 0 to 3FFFFFFFFFF

MinPrEvEnum MpRev#
// SCPI: [SOURce<HW>]:BB:C2K:BSTation:SYNC:MPRev
MinPrEvEnum value = driver.Source.Bb.C2K.Bstation.Sync.MpRev;
driver.Source.Bb.C2K.Bstation.Sync.MpRev = MinPrEvEnum._2;

Sets the Minimum Protocol Revision Level. The base station sets this field to prevent mobile stations which cannot be supported by the base station from accessing the CDMA system.

mpRev: 2 | 8 Range: 2 to 8

int Nid#
// SCPI: [SOURce<HW>]:BB:C2K:BSTation:SYNC:NID
int value = driver.Source.Bb.C2K.Bstation.Sync.Nid;
driver.Source.Bb.C2K.Bstation.Sync.Nid = 1;

Sets the Network Identification. The NID serves as a sub-identifier of a CDMA system as defined by the owner of the SID.

nid: integer Range: 0 to Max Uint16

int Prev#
// SCPI: [SOURce<HW>]:BB:C2K:BSTation:SYNC:PREV
int value = driver.Source.Bb.C2K.Bstation.Sync.Prev;
driver.Source.Bb.C2K.Bstation.Sync.Prev = 1;

Sets the Protocol Revision Level, i.e. specifies the CDMA2000 system release number. The table below gives the cross-reference between the P_REV values and the CDMA2000 Releases. P_REV / CDMA2000 Release

  • 1 / Korean PCS(Band Class4) , USPCS(Band Class1)

  • 2 / IS-95

  • 3 / TBS74

  • 4 / IS-95A

  • 5 / IS-95B

  • 6 / IS2000 Release 0

  • 7 / IS2000 Release A

  • 8 / IS2000 Release B

prev: integer Range: 1 to 8
