Source:Bb:Gnss:Time:Start:Glonass#

SCPI Commands

[SOURce<HW>]:BB:GNSS:TIME:STARt:GLONass:DATE
[SOURce<HW>]:BB:GNSS:TIME:STARt:GLONass:OFFSet
[SOURce<HW>]:BB:GNSS:TIME:STARt:GLONass:TIME

Direct SCPI Members

class Date_Data

Structure for reading output parameters.

int Year

integer Range: 1980 to 9999

int Month

integer Range: 1 to 12

int Day

integer Range: 1 to 31

Date_Data Date#
// SCPI: [SOURce<HW>]:BB:GNSS:TIME:STARt:GLONass:DATE
Date_Data value = driver.Source.Bb.Gnss.Time.Start.Glonass.Date;

Queries the date at the simulation start time of the selected navigation standard.

For return value, see the help for Date_Data structure arguments

double Offset#
// SCPI: [SOURce<HW>]:BB:GNSS:TIME:STARt:GLONass:OFFSet
double value = driver.Source.Bb.Gnss.Time.Start.Glonass.Offset;

Queries the time offset between the time in the navigation standard and UTC.

utcOffset: float Range: -1E6 to 1E6
