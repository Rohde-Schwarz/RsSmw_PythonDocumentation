Direct SCPI Members

double Crange#
// SCPI: [SOURce<HW>]:POWer:SPC:CRANge
double value = driver.Source.Power.Spc.Crange;
driver.Source.Power.Spc.Crange = 1.0;

Defines the capture range of the power control system. Within the range: Target Level +/- Catch Range the power control locks and tries to achieve the target level. Readings outside the range are not considered.

powCntrlCrange: float Range: 0 to 50

int Delay#
// SCPI: [SOURce<HW>]:POWer:SPC:DELay
int value = driver.Source.Power.Spc.Delay;
driver.Source.Power.Spc.Delay = 1;

Sets a waiting time for the generator to adjust the output level. After the delay time has elapsed, the power sensor measures the next value.

powCntrlDelay: integer Range: 0 to 1000

SensorModeAllEnum Mode#
// SCPI: [SOURce<HW>]:POWer:SPC:MODE
SensorModeAllEnum value = driver.Source.Power.Spc.Mode;
driver.Source.Power.Spc.Mode = SensorModeAllEnum.AUTO;

Selects the measurement mode for the power sensor.

controlMode: AUTO | SINGle AUTO Measures the level values continuously. SINGle Executes one measurement, triggered by the command method RsSmw.Source.Power.Spc.Single.Set().

bool Peak#
// SCPI: [SOURce<HW>]:POWer:SPC:PEAK
bool value = driver.Source.Power.Spc.Peak;
driver.Source.Power.Spc.Peak = false;

Activates power control by means of the peak power values, provided the power sensor supports this function.

powCntrlPeak: 1 | ON | 0| OFF

PowCntrlSelectEnum Select#
// SCPI: [SOURce<HW>]:POWer:SPC:SELect
PowCntrlSelectEnum value = driver.Source.Power.Spc.Select;
driver.Source.Power.Spc.Select = PowCntrlSelectEnum.SENS1;

Selects the power sensor used for power control.

powCntrlSelect: SENS1 | SENS2 | SENS3 | SENS4 | SENSor1 | SENSor2 | SENSor3 | SENSor4

bool State#
// SCPI: [SOURce<HW>]:POWer:SPC:STATe
bool value = driver.Source.Power.Spc.State;
driver.Source.Power.Spc.State = false;

Starts power control using the selected sensor. The control loop periodically adjusts the output level of the signal generator. After switching off, the running loop is completed.

powCntrlState: 1 | ON | 0| OFF

double Target#
// SCPI: [SOURce<HW>]:POWer:SPC:TARGet
double value = driver.Source.Power.Spc.Target;
driver.Source.Power.Spc.Target = 1.0;

Sets the target level required at the DUT. To define the unit of the power value, use command method RsSmw.Unit.Power.

powCntrlTarget: float Range: -50 to 30

bool Warning#
// SCPI: [SOURce<HW>]:POWer:SPC:WARNing
bool value = driver.Source.Power.Spc.Warning;

Queries if the activated power control works properly. If the power control does not work, the query returns warning state 1. On the screen, the R&S SMW200A indicates a warning icon.

warningState: 1 | ON | 0| OFF
