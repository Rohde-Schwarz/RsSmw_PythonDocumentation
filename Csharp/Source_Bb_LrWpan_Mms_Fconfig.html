HrpUwbDeltaLengthEnum Dlength#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:MMS:FCONfig:DLENgth
HrpUwbDeltaLengthEnum value = driver.Source.Bb.LrWpan.Mms.Fconfig.Dlength;
driver.Source.Bb.LrWpan.Mms.Fconfig.Dlength = HrpUwbDeltaLengthEnum.DL_16;

Sets the delta length. The length depends on the HRP UWB mode and bandwidth.

deltaLength: DL_4 | DL_16 | DL_64

HrpUwbSfdlEngthEnum SfdLength#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:MMS:FCONfig:SFDLength
HrpUwbSfdlEngthEnum value = driver.Source.Bb.LrWpan.Mms.Fconfig.SfdLength;

Queries the symbol length of the start-of-frame delimiter (SFD) . The SFD length depends on the set SFD symbol sequence, see Table “SFD: indices and lengths”. In the mode [:SOURce<hw>]:BB:HUWB:STD OQPSK the SFD length is SFDL_2.

sfdLength: SFDL_8 | SFDL_64 | SFDL_2 | SFDL_4 | SFDL_16 | SFDL_32

HrpUwbSyncLengthEnum SynLength#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:MMS:FCONfig:SYNLength
HrpUwbSyncLengthEnum value = driver.Source.Bb.LrWpan.Mms.Fconfig.SynLength;
driver.Source.Bb.LrWpan.Mms.Fconfig.SynLength = HrpUwbSyncLengthEnum.SL_1024;

Sets the sync length. In the mode [:SOURce<hw>]:BB:HUWB:STD OQPSK the sync length is set automatically, depending on the selected operating band and SFD.

syncLength: SL_16 | SL_24 | SL_32 | SL_48 | SL_64 | SL_96 | SL_128 | SL_256 | SL_1024 | SL_4096
