Direct SCPI Members

int Frequency#
// SCPI: TEST:BB:DATA:FREQuency
int value = driver.Test.Bb.Data.Frequency;
driver.Test.Bb.Data.Frequency = 1;

Sets the clock frequency for the BER/BLER test generator.

clock: integer Range: 100 to 1E8

int OffTime#
// SCPI: TEST:BB:DATA:OFFTime
int value = driver.Test.Bb.Data.OffTime;
driver.Test.Bb.Data.OffTime = 1;

Sets the on/off time of the data enable time interval of the BER/BLER test generator.

offTime: integer Range: 0 to Max Uint32, Unit: Bit

int Ontime#
// SCPI: TEST:BB:DATA:ONTime
int value = driver.Test.Bb.Data.Ontime;
driver.Test.Bb.Data.Ontime = 1;

Sets the on/off time of the data enable time interval of the BER/BLER test generator.

int Rdelay#
// SCPI: TEST:BB:DATA:RDELay
int value = driver.Test.Bb.Data.Rdelay;
driver.Test.Bb.Data.Rdelay = 1;

For “External Restart = On, sets the delay time for the restart signal of the BER/BLER test generator.

restartDelay: integer Range: 0 to Max Uint32

bool State#
// SCPI: TEST:BB:DATA:STATe
bool value = driver.Test.Bb.Data.State;
driver.Test.Bb.Data.State = false;

Activates the test generator for the bit or block error rate measurement.

state: 1 | ON | 0| OFF

BertTestModeEnum Type#
// SCPI: TEST:BB:DATA:TYPE
BertTestModeEnum value = driver.Test.Bb.Data.Type;
driver.Test.Bb.Data.Type = BertTestModeEnum.BER;

Selects the type of error measurement.

type: BER | BLER
