The command determines the data source for the PRACH.

data ZERO | ONE | PATTern | PN9 | PN11 | PN15 | PN16 | PN20 | PN21 | PN23 | DLISt PNxx The pseudo-random sequence generator is used as the data source. Different random sequence lengths can be selected. DLISt A data list is used. The data list is selected with the command method RsSmw.Source.Bb.W3Gpp.Mstation.Prach.Data.Dselect.Set(). ZERO | ONE Internal 0 and 1 data is used. PATTern Internal data is used. The bit pattern for the data is defined by the command method RsSmw.Source.Bb.W3Gpp.Mstation.Prach.Data.Pattern.Set().

mobileStation Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
