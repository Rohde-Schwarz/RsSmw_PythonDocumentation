Direct SCPI Members

void Set ( )#

// SCPI: [SOURce<HW>]:LIST:DEXChange:EXECute
driver.Source.List.Dexchange.Execute.Set();
driver.Source.List.Dexchange.Execute.SetAndWait();
driver.Source.List.Dexchange.Execute.SetAndWait(1000);

Executes the import or export of the selected list file, according to the previously set transfer direction with command method RsSmw.Source.List.Dexchange.Mode

SetAndWait is the same as Set, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
