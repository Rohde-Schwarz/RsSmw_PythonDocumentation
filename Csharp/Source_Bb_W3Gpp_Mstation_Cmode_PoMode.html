The command selects the power offset mode.

poMode AUTO | USER AUTO The power offset is obtained by pilot bit ratio as follows: Number of pilots bits of non-compressed slots / Number of pilot bits by compressed slots. USER The power offset is defined by command method RsSmw.Source.Bb.W3Gpp.Bstation.Cmode.Poffset.Set().

mobileStation Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
