// Create a clone of the original group, that exists independently

Direct SCPI Members

int Count#
// SCPI: [SOURce<HW>]:BB:ARBitrary:MCARrier:CARRier:COUNt
int value = driver.Source.Bb.Arbitrary.Mcarrier.Carrier.Count;
driver.Source.Bb.Arbitrary.Mcarrier.Carrier.Count = 1;

Sets the number of carriers in the ARB multicarrier waveform.

count: integer Range: 1 to 512

ArbMultCarrSpacModeEnum Mode#
// SCPI: [SOURce<HW>]:BB:ARBitrary:MCARrier:CARRier:MODE
ArbMultCarrSpacModeEnum value = driver.Source.Bb.Arbitrary.Mcarrier.Carrier.Mode;
driver.Source.Bb.Arbitrary.Mcarrier.Carrier.Mode = ArbMultCarrSpacModeEnum.ARBitrary;

Sets the carrier frequency mode for the single carriers.

mode: EQUidistant | ARBitrary

double Spacing#
// SCPI: [SOURce<HW>]:BB:ARBitrary:MCARrier:CARRier:SPACing
double value = driver.Source.Bb.Arbitrary.Mcarrier.Carrier.Spacing;
driver.Source.Bb.Arbitrary.Mcarrier.Carrier.Spacing = 1.0;

Sets the frequency spacing between adjacent carriers of the multicarrier waveform. See also “Defining the carrier frequency”.

spacing: float Range: 0.0 to depends on options, for example 120E6 (R&S SMW-B10) , Unit: Hz
