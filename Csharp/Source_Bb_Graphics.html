TranRecSizeEnum Add#
// SCPI: [SOURce]:BB:GRAPhics:ADD

driver.Source.Bb.Graphics.Add = TranRecSizeEnum.MAXimized;

Adds a graphical signal display (according to the current MODE, SOURce, SRATe:* and TRIGger:* settings) .

Size: MAXimized | MINimized

void Close ( )#
void CloseAndWait ( )#
void CloseAndWait ( int opcTimeoutMs )
// SCPI: [SOURce]:BB:GRAPhics:CLOSe
driver.Source.Bb.Graphics.Close();
driver.Source.Bb.Graphics.CloseAndWait();
driver.Source.Bb.Graphics.CloseAndWait(1000);

Closes all graphical signal displays.

CloseAndWait is the same as Close, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.

bool FftFscale#
// SCPI: [SOURce]:BB:GRAPhics:FFTFscale
bool value = driver.Source.Bb.Graphics.FftFscale;
driver.Source.Bb.Graphics.FftFscale = false;

Defines the normalization of the power values in the power spectrum diagram.

state: 1 | ON | 0| OFF 1 Normalized power in dBFS 0 Shows power distribution in dB/Hz
