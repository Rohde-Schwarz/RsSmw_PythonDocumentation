Allows you to send SCPI commands to the RF instruments connected to the R&S SMW200A.

sendScpiCommand “SCPI syntax” String containing an SCPI command (query or setting)

iqConnector Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
