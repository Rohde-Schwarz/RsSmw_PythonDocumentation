Adds manually an external instrument to the list of available instruments.

instrName String Alias name of the instrument

hwChan String Hardware channel (USB or LAN) used by the remote channel to the external instrument Range: “LAN” to “USB”

tcpIporUsbAddr String IP address or hostname of the connected external instrument

rfPathNumber String Determines the number of RF paths the external instrument is equipped with Range: “1” to “2”
