Direct SCPI Members

int Level#
// SCPI: [SOURce<HW>]:BB:WLNN:CLIPping:LEVel
int value = driver.Source.Bb.Wlnn.Clipping.Level;
driver.Source.Bb.Wlnn.Clipping.Level = 1;

Sets the limit for level clipping. This value indicates at what point the signal is clipped. It is specified as a percentage, relative to the highest level. 100% indicates that clipping does not take place. Level clipping is activated if method RsSmw.Source.Bb.Wlnn.Clipping.State is set to ON.

level: integer Range: 1 PCT to 100 PCT

ClipModeEnum Mode#
// SCPI: [SOURce<HW>]:BB:WLNN:CLIPping:MODE
ClipModeEnum value = driver.Source.Bb.Wlnn.Clipping.Mode;
driver.Source.Bb.Wlnn.Clipping.Mode = ClipModeEnum.SCALar;

Sets the method for level clipping.

mode: VECTor | SCALar VECTor The reference level is the amplitude i+jq. SCALar The reference level is the absolute maximum of the I and Q values.

bool SppsState#
// SCPI: [SOURce<HW>]:BB:WLNN:CLIPping:SPPState
bool value = driver.Source.Bb.Wlnn.Clipping.SppsState;
driver.Source.Bb.Wlnn.Clipping.SppsState = false;

Applies vector clipping to fields L-SIG, RL-SIG, U-SIG and EHT-SIG.

state: 1 | ON | 0| OFF

bool State#
// SCPI: [SOURce<HW>]:BB:WLNN:CLIPping:STATe
bool value = driver.Source.Bb.Wlnn.Clipping.State;
driver.Source.Bb.Wlnn.Clipping.State = false;

Activates level clipping (Clipping) . The value is defined with method RsSmw.Source.Bb.Wlnn.Clipping.Level, the mode of calculation with method RsSmw.Source.Bb.Wlnn.Clipping.Mode.

state: 1 | ON | 0| OFF
