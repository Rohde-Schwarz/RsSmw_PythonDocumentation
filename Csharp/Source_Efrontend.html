Direct SCPI Members

EfePowAttModeEnum Amode#
// SCPI: [SOURce<HW>]:EFRontend:AMODe
EfePowAttModeEnum value = driver.Source.Efrontend.Amode;
driver.Source.Efrontend.Amode = EfePowAttModeEnum.AOFFset;

Sets the attenuator mode of the external frontend.

attenuationMode: AUTO | MANual | AOFFset AUTO Sets the attenuation value automatically to the attenuation value provided from the connected external frontend. MANual Sets an attenuation value manually. AOFFset Requires frontend R&S FE170ST or R&S FE110ST. You can define an offset value which is added to the attenuation value provided from the connected external frontend.

ConModeEnum Cmode#
// SCPI: [SOURce<HW>]:EFRontend:CMODe
ConModeEnum value = driver.Source.Efrontend.Cmode;
driver.Source.Efrontend.Cmode = ConModeEnum.AUTO;

Sets the mode of the SSL control connection between R&S SMW200A and external frontend.

feConnMode: AUTO | LOCK | RXTX AUTO The R&S SMW200A locks external frontend, when activating the RF output at the R&S SMW200A (:OUTPut1 ON ) for output of the IF signal. The R&S SMW200A unlocks external frontend, when deactivating the RF output at the R&S SMW200A (:OUTPut1 OFF) . LOCK The external frontend is locked permanently. No other instrument can take over control. RXTX Requires an R&S FE50DTR connected to the R&S SMW200A. Connection mode for simultaneous Rx (receive) operation and Tx (transmit) operation of an R&S FE50DTR. Set this mode, if your test setup requires a release of connection lock. A connected vector signal analyzer can lock the external frontend for Rx operation.

string Opt#
// SCPI: [SOURce<HW>]:EFRontend:OPT
string value = driver.Source.Efrontend.Opt;

Option identification query Queries the options included in the external frontend. For more information, refer to the specifications document.

optString: string The query returns a list of options. The options are returned at fixed positions in a comma-separated string. A zero is returned for options that are not installed.

FenUmbRfConEnum RfConnector#
// SCPI: [SOURce<HW>]:EFRontend:RFConnector
FenUmbRfConEnum value = driver.Source.Efrontend.RfConnector;
driver.Source.Efrontend.RfConnector = FenUmbRfConEnum.NONE;

Queries the active RF output connector at the connected RF frontend.

feOutputPath: NONE | RFA | RFB NONE No frontend connected. RFA Output connector “RF A” is active at the external frontend. RFB Output connector “RF B” is active at the external frontend.
