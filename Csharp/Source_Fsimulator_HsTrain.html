Direct SCPI Members

double Fdoppler#
// SCPI: [SOURce<HW>]:FSIMulator:HSTRain:FDOPpler
double value = driver.Source.Fsimulator.HsTrain.Fdoppler;

Queries the maximum Doppler Shift for the selected configuration.

fdoppler: float Range: 0 to depends on settings

double Kfactor#
// SCPI: [SOURce<HW>]:FSIMulator:HSTRain:KFACtor
double value = driver.Source.Fsimulator.HsTrain.Kfactor;
driver.Source.Fsimulator.HsTrain.Kfactor = 1.0;

Sets the Rician factor K for high-speed train scenario 2.

kfactor: float Range: -30 to 30

FadingProfileBenum Profile#
// SCPI: [SOURce<HW>]:FSIMulator:HSTRain:PROFile
FadingProfileBenum value = driver.Source.Fsimulator.HsTrain.Profile;
driver.Source.Fsimulator.HsTrain.Profile = FadingProfileBenum.BELLindoor;

Determines the fading profile for the selected scenario. The fading profile determines which transmission path is simulated.

profile: SPATh | PDOPpler | RAYLeigh

double Soffset#
// SCPI: [SOURce<HW>]:FSIMulator:HSTRain:SOFFset
double value = driver.Source.Fsimulator.HsTrain.Soffset;
driver.Source.Fsimulator.HsTrain.Soffset = 1.0;

Shifts the high speed train profile in time. The maximum possible shift is calculated as max = 2*DS/v ,where:

  • DS is the distance in meters between the train and the BS at the beginning of the simulation

  • v is the velocity of the train in m/s

startOffset: float Range: 0 to 429.49672950

double Speed#
// SCPI: [SOURce<HW>]:FSIMulator:HSTRain:SPEed
double value = driver.Source.Fsimulator.HsTrain.Speed;
driver.Source.Fsimulator.HsTrain.Speed = 1.0;

Sets the velocity parameter , i.e. the speed of the moving receiver in m/s.

speed: float Range: 0.001 to depends on settings

bool State#
// SCPI: [SOURce<HW>]:FSIMulator:HSTRain:STATe
bool value = driver.Source.Fsimulator.HsTrain.State;
driver.Source.Fsimulator.HsTrain.State = false;

Activates/deactivates simulation of High Speed Train propagation according to the selected scenario 1 or 3.

state: 1 | ON | 0| OFF
