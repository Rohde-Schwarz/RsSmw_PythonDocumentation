The command sets the slot format for the selected enhanced DPCH of base station 1. The slot format is fixed for channel-coded measurement channels conforming to the standard - “Reference Measurement Channel”. Changing the slot format automatically activates User coding (W3GP:BST:ENH:CHAN<11…13>:DPCH:CCOD:TYPE USER) . The slot format also fixes the symbol rate, bits per frame, pilot length and TFCI state parameters. When a channel coding type conforming to the standard is selected (method RsSmw.Source.Bb.W3Gpp.Bstation.Enhanced.Channel.Dpch.Ccoding.Type.Set) and channel coding is activated, the slot format is (method RsSmw.Source.Bb.W3Gpp.Bstation.Enhanced.Channel.Dpch.Ccoding.State.Set) automatically set to the associated value. Changing the slot format automatically activates User coding (W3GP:BST:ENH:CHAN<11…13>:DPCH:CCOD:TYPE USER) . The command sets the symbol rate (W3GP:BST:ENH:CHAN:DPCH:CCOD:SRAT) , the bits per frame (W3GP:BST:ENH:CHAN:DPCH:CCOD:BPFR) , the pilot length (W3GP:BST1:CHAN:DPCC:PLEN) , and the TFCI state (W3GP:BST1:CHAN:DPCC:TFCI STAT) to the associated values.

sformat integer Range: 0 to dynamic

channelNull Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
