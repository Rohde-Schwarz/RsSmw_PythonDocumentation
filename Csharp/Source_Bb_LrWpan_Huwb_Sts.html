Direct SCPI Members

string Cpart#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:HUWB:STS:CPARt
string value = driver.Source.Bb.LrWpan.Huwb.Sts.Cpart;
driver.Source.Bb.LrWpan.Huwb.Sts.Cpart = "rawAbc";

Sets the counter part of the V value. The value is a 32-bit value in hexadecimal representation.

counterPart: integer

HrpUwbStsDeltaLenEnum Dlen#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:HUWB:STS:DLEN
HrpUwbStsDeltaLenEnum value = driver.Source.Bb.LrWpan.Huwb.Sts.Dlen;

Queries the delta length of the scrambled timestamp sequence (STS) . The delta length depends on the HRP UWB mode.

deltaLength: DL_4 | DL_8

bool Dls#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:HUWB:STS:DLS
bool value = driver.Source.Bb.LrWpan.Huwb.Sts.Dls;
driver.Source.Bb.LrWpan.Huwb.Sts.Dls = false;

Activates the STS source. If activated, you can select an STS data list from a designated folder to import a user defined STS sequence.

stsDatalist: 1 | ON | 0| OFF

string Key#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:HUWB:STS:KEY
string value = driver.Source.Bb.LrWpan.Huwb.Sts.Key;
driver.Source.Bb.LrWpan.Huwb.Sts.Key = "rawAbc";

Sets the key value of the scrambled timestamp sequence (STS) . The value is a 128-bit value in hexadecimal representation.

key: integer

HrpUwbStspAcketConfigEnum Pc#
// SCPI: [SOURce<HW>]:BB:[LRWPan]:HUWB:STS:PC

Requires [:SOURce<hw>]:BB:LRWPan | HUWB:STD BPRF | HPRF | EHPRF. Sets the scrambled timestamp sequence (STS) packet configuration.

spc: SPC_0 | SPC_1 | SPC_2 | SPC_3
