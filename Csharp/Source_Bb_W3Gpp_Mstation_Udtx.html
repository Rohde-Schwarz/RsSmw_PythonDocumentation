int Offset#
// SCPI: [SOURce<HW>]:BB:W3GPp:MSTation:UDTX:OFFSet
int value = driver.Source.Bb.W3Gpp.Mstation.Udtx.Offset;
driver.Source.Bb.W3Gpp.Mstation.Udtx.Offset = 1;

Sets the parameter UE_DTX_DRX_Offset and determines the start offset in subframes of the first uplink DPCCH burst (after the preamble) . The offset is applied only for bursts belonging to the DPCCH burst pattern; HS-DPCCH or E-DCH transmissions are not affected.

offset: integer Range: 0 to 159

bool State#
// SCPI: [SOURce<HW>]:BB:W3GPp:MSTation:UDTX:STATe
bool value = driver.Source.Bb.W3Gpp.Mstation.Udtx.State;
driver.Source.Bb.W3Gpp.Mstation.Udtx.State = false;

Enables/disables UL-DTX or user scheduling, as selected with the command method RsSmw.Source.Bb.W3Gpp.Mstation.Udtx.Mode. Enabling the UL-DTX deactivates the DPDCH and the HSUPA FRC. Enabled user scheduling deactivates the HSUPA FRC.

state: 1 | ON | 0| OFF
