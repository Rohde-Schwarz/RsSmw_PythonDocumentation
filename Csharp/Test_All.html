Test:All#

SCPI Commands

Direct SCPI Members

TestEnum Result#
// SCPI: TEST<HW>:ALL:RESult
TestEnum value = driver.Test.All.Result;

Queries the progress of the performed selftest. Start the selftest with method RsSmw.Test.All.Start.

result: 0 | 1| RUNning | STOPped

void Start ( )#
void StartAndWait ( )#
void StartAndWait ( int opcTimeoutMs )
// SCPI: TEST<HW>:ALL:STARt
driver.Test.All.Start();
driver.Test.All.StartAndWait();
driver.Test.All.StartAndWait(1000);

Starts the selftest. Use the command method RsSmw.Test.All.Result to query the progress of the test.

StartAndWait is the same as Start, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
