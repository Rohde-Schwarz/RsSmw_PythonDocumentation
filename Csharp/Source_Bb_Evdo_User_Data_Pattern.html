Sets the data pattern for the data portion of the packets sent to the user. The most significant bit (MSB) of this value is the MSB of the packet and the word is repeated to fill all space within the packet.

settings For set / get value, see the help for Pattern_Data structure arguments

userIx Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
