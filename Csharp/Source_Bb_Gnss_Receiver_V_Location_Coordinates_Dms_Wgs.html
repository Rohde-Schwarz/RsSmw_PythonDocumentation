SCPI Commands

Direct SCPI Members

class Wgs_Data

Structure for setting input parameters.

int LongitudeDeg

integer Defines the longitude degrees. Range: 0 to 180

int LongitudeMin

integer Defines the longitude minutes. Range: 0 to 59

double LongitudeSec

float Defines the longitude seconds. Range: 0 to 59.999

LongitudeDirEnum LongitudeDir

EAST | WEST Defines the longitude direction.

int LatitudeDeg

integer Defines the latitude degrees. Range: 0 to 90

int LatitudeMin

integer Defines the latitude minutes. Range: 0 to 59

double LatitudeSec

float Defines the latitude seconds. Range: 0 to 59.999

LatitudeDirEnum LatitudeDir

NORTh | SOUTh Defines the latitude direction.

double Altitude

float Defines the altitude. The altitude value is in meters and is the height above the reference ellipsoid. Range: -10E3 to 50E6
