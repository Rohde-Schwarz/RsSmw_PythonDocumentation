Source:Iq:Output:Analog:Setting#

SCPI Commands

[SOURce<HW>]:IQ:OUTPut:[ANALog]:SETTing:CATalog
[SOURce<HW>]:IQ:OUTPut:[ANALog]:SETTing:DELete
[SOURce<HW>]:IQ:OUTPut:[ANALog]:SETTing:LOAD
[SOURce<HW>]:IQ:OUTPut:[ANALog]:SETTing:STORe

Direct SCPI Members

List<string>Catalog#
// SCPI: [SOURce<HW>]:IQ:OUTPut:[ANALog]:SETTing:CATalog
List<string> value = driver.Source.Iq.Output.Analog.Setting.Catalog;

Queries the files with I/Q output settings in the default directory. Listed are files with the file extension iqout. Refer to “Accessing Files in the Default or Specified Directory” for general information on file handling in the default and in a specific directory.

catalog: string

void Delete ( string filename )#
// SCPI: [SOURce<HW>]:IQ:OUTPut:[ANALog]:SETTing:DELete
driver.Source.Iq.Output.Analog.Setting.Delete("abc");

Deletes the selected file from the default or specified directory. Deleted are files with the file extension iqout. Refer to “Accessing Files in the Default or Specified Directory” for general information on file handling in the default and in a specific directory.

filename “filename” Filename or complete file path

void Load ( string filename )#
// SCPI: [SOURce<HW>]:IQ:OUTPut:[ANALog]:SETTing:LOAD
driver.Source.Iq.Output.Analog.Setting.Load("abc");

Loads the selected file from the default or the specified directory. Loaded are files with extension iqout. Refer to “Accessing Files in the Default or Specified Directory” for general information on file handling in the default and in a specific directory.

filename “filename” Filename or complete file path

string Store#
// SCPI: [SOURce<HW>]:IQ:OUTPut:[ANALog]:SETTing:STORe

driver.Source.Iq.Output.Analog.Setting.Store = "abc";

Stores the current settings into the selected file; the file extension (iqout) is assigned automatically. Refer to “Accessing Files in the Default or Specified Directory” for general information on file handling in the default and in a specific directory.

Filename: “filename” Filename or complete file path
