Direct SCPI Members

void Preset ( )#
void PresetAndWait ( )#
void PresetAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:BB:DVB:PRESet
driver.Source.Bb.Dvb.Preset();
driver.Source.Bb.Dvb.PresetAndWait();
driver.Source.Bb.Dvb.PresetAndWait(1000);

Sets all parameters of the application to their default values. These values are the *RST values of the commands of the application.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.

DvbStandardEnum Standard#
// SCPI: [SOURce<HW>]:BB:DVB:STANdard
DvbStandardEnum value = driver.Source.Bb.Dvb.Standard;
driver.Source.Bb.Dvb.Standard = DvbStandardEnum.DVBH;

Selects the DVB standard to be used.

standard: DVBH | DVBT | DVBS | DVBX | DVBR

bool State#
// SCPI: [SOURce<HW>]:BB:DVB:STATe
bool value = driver.Source.Bb.Dvb.State;
driver.Source.Bb.Dvb.State = false;

Enables the baseband signal application and disables all the other baseband signal applications in the same signal path.

state: 1 | ON | 0| OFF
