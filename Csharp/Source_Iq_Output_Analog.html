Direct SCPI Members

bool State#
// SCPI: [SOURce<HW>]:IQ:OUTPut:ANALog:STATe
bool value = driver.Source.Iq.Output.Analog.State;
driver.Source.Iq.Output.Analog.State = false;

Activates the specified analog I/Q output. Note: By default, the output connectors [I/Q Out x] are deactivated.

state: 1 | ON | 0| OFF

IqOutModeEnum Mode#
// SCPI: [SOURce<HW>]:IQ:OUTPut:[ANALog]:MODE
IqOutModeEnum value = driver.Source.Iq.Output.Analog.Mode;
driver.Source.Iq.Output.Analog.Mode = IqOutModeEnum.FIXed;

Determines the mode for setting the output parameters.

mode: FIXed | VARiable FIXed Locks the I/Q output settings VARiable Unlocks the settings

void Preset ( )#
void PresetAndWait ( )#
void PresetAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:IQ:OUTPut:[ANALog]:PRESet
driver.Source.Iq.Output.Analog.Preset();
driver.Source.Iq.Output.Analog.PresetAndWait();
driver.Source.Iq.Output.Analog.PresetAndWait(1000);

Sets the default settings (*RST values specified for the commands) . Not affected are:

  • The state set with the command method RsSmw.Source.Iq.Output.Analog.State.

  • If SCONfiguration:EXTernal:PBEHaviour 1, the I/Q ouptput type set with the command method RsSmw.Source.Iq.Output.Analog.Type.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
