Utilities#

Common utility interface for every driver. Access it through driver.Utilities.

RsSmw_Utilities Utilities#
var utils = driver.Utilities;

Utility functions common for all instrument drivers.

Status and synchronization#

bool QueryOpc ( )#
// SCPI: *OPC?
bool complete = driver.Utilities.QueryOpc();

SCPI command *OPC?. Waits until the instrument reports operation complete. Exceptions: VisaException, VisaTimeoutException.

bool QueryOpc ( int visaTimeout )
// SCPI: *OPC?
bool complete = driver.Utilities.QueryOpc(3000);

Same as QueryOpc(). visaTimeout is used only for this call, then the previous VISA timeout is restored. Exceptions: VisaException, VisaTimeoutException.

bool InstrumentStatusChecking#
bool checking = driver.Utilities.InstrumentStatusChecking;
driver.Utilities.InstrumentStatusChecking = true;

When true (default), driver methods send SYST:ERR? after each command and throw if the instrument reports an error. Keep status checking on. Switch it off only when you need maximum speed.

bool OpcQueryAfterEachSetting#
driver.Utilities.OpcQueryAfterEachSetting = true;

When true (default is false), the driver sends *OPC? after every write. Queries are left unchanged. Use it when the sequence must run command after command.

void ClearStatus ( )#
driver.Utilities.ClearStatus();

Clears the instrument status system, the session I/O buffers, and the instrument error queue. Exceptions: VisaException, VisaTimeoutException, RsSmwException.

string QueryOldestError ( )#
// SCPI: SYSTem:ERRor?
string error = driver.Utilities.QueryOldestError();

SCPI command SYSTem:ERRor?. Reads and deletes the oldest error and returns its message. An empty queue returns No Error. Exceptions: VisaException, VisaTimeoutException.

IEnumerable<string>QueryAllErrors ( )#
// SCPI: SYSTem:ERRor?
IEnumerable<string> errors = driver.Utilities.QueryAllErrors();

SCPI command SYSTem:ERRor?. Reads and clears the error queue, from the oldest error to the newest. An empty queue returns an empty list. Exceptions: VisaException, VisaTimeoutException.

void CheckStatus ( )#
driver.Utilities.CheckStatus();

Throws InstrumentStatusException when the instrument error queue is not empty. Exceptions: VisaException, VisaTimeoutException, InstrumentStatusException.

void Reset ( )#
// SCPI: *RST
driver.Utilities.Reset();

SCPI command *RST. Clears the status, sends the reset, waits until it finishes, and calls DefaultInstrumentSetup(). Exceptions: VisaException, VisaTimeoutException, RsSmwException, InstrumentStatusException.

void DefaultInstrumentSetup ( )#
driver.Utilities.DefaultInstrumentSetup();

Custom steps performed when the session opens and when Reset() is called.

int SelfTest ( )#
// SCPI: *TST?
int result = driver.Utilities.SelfTest();

SCPI command *TST?. Returns the self-test result code. 0 means the self-test passed. Exceptions: VisaException, VisaTimeoutException, RsSmwException, InstrumentStatusException.
