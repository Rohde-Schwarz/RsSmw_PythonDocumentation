Direct SCPI Members

double Ci#
// SCPI: [SOURce<HW>]:NOISe:IMPulsive:CI
double value = driver.Source.Noise.Impulsive.Ci;
driver.Source.Noise.Impulsive.Ci = 1.0;

Specifies the ratio of the wanted signal (C) to the impulsive noise signal (I) .

iplsCi: float Range: -35 to 60

double Frame#
// SCPI: [SOURce<HW>]:NOISe:IMPulsive:FRAMe
double value = driver.Source.Noise.Impulsive.Frame;
driver.Source.Noise.Impulsive.Frame = 1.0;

Sets the time intervals at which the bursts occur.

iplsFrameDuration: float Range: 0.1E-3 to 1

double MaxSpace#
// SCPI: [SOURce<HW>]:NOISe:IMPulsive:MAXSpace
double value = driver.Source.Noise.Impulsive.MaxSpace;
driver.Source.Noise.Impulsive.MaxSpace = 1.0;

If more than 1 pulse per burst are enabled (method RsSmw.Source.Noise.Impulsive.Pulsee.g. 2) , sets the minimum/maximum spacing between 2 pulses within a burst.

iplsSpaceMax: float Range: 0.25E-6 to 0.01

double MinSpace#
// SCPI: [SOURce<HW>]:NOISe:IMPulsive:MINSpace
double value = driver.Source.Noise.Impulsive.MinSpace;
driver.Source.Noise.Impulsive.MinSpace = 1.0;

If more than 1 pulse per burst are enabled (method RsSmw.Source.Noise.Impulsive.Pulsee.g. 2) , sets the minimum/maximum spacing between 2 pulses within a burst.

int Pulse#
// SCPI: [SOURce<HW>]:NOISe:IMPulsive:PULSe
int value = driver.Source.Noise.Impulsive.Pulse;
driver.Source.Noise.Impulsive.Pulse = 1;

Sets the number of noise pulses per burst.

iplsPulse: integer Range: 1 to Max Uint16

bool State#
// SCPI: [SOURce<HW>]:NOISe:IMPulsive:[STATe]
bool value = driver.Source.Noise.Impulsive.State;
driver.Source.Noise.Impulsive.State = false;

Enables or disables the impulsive noise generator.

impulsiveState: 1 | ON | 0| OFF
