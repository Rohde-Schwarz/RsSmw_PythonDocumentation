SCPI Commands

// SCPI: [SOURce<HW>]:BB:TDSCdma:UP:CELL<ST>:SLOT<CH0>:PRAC:PTS:PCORrection
double value = driver.Source.Bb.Tdscdma.Up.Cell.Slot.Prac.Pts.Pcorrection.Get();
double value = driver.Source.Bb.Tdscdma.Up.Cell.Slot.Prac.Pts.Pcorrection.Get(CellRepCap.Default, SlotNullRepCap.Default);

Queries the power correction of the UpPTS. The value is computed based on:

  • UpPTS power BB:TDSC:UP:CELL:SLOT:PRAC:PTS:POW

  • Power step BB:TDSC:UP:CELL:SLOT:PRAC:PTS:PST

  • Message power BB:TDSC:UP:CELL:SLOT:PRAC:MSG:POW

  • UpPTS length, message length BB:TDSC:UP:CELL:SLOT:PRAC:MSG:LENG

  • ARB sequence length BB:TDSC:SLEN

pcorrection: float Range: -1E10 to 1E10

cell Repeated capability selector

slotNull Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
