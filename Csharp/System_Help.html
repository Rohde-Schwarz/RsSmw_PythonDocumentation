void Export ( )#
void ExportAndWait ( )#
void ExportAndWait ( int opcTimeoutMs )
// SCPI: SYSTem:HELP:EXPort
driver.System.Help.Export();
driver.System.Help.ExportAndWait();
driver.System.Help.ExportAndWait(1000);

Saves the online help as zip archive in the user directory.

ExportAndWait is the same as Export, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
