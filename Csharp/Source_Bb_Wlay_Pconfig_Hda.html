Direct SCPI Members

int Bmcs#
// SCPI: [SOURce<HW>]:BB:WLAY:PCONfig:HDA:BMCS
int value = driver.Source.Bb.Wlay.Pconfig.Hda.Bmcs;
driver.Source.Bb.Wlay.Pconfig.Hda.Bmcs = 1;

Selects the modulation and coding scheme (MCS) for all spatial streams. The current firmware supports MSC for EDMG SC mode only, see Table “MCS for IEEE 802.11ay EDMG SC mode”, for example.

baseMcs: integer Range: 1 to 21

WlanayBwEnum Bw#
// SCPI: [SOURce<HW>]:BB:WLAY:PCONfig:HDA:BW
WlanayBwEnum value = driver.Source.Bb.Wlay.Pconfig.Hda.Bw;
driver.Source.Bb.Wlay.Pconfig.Hda.Bw = WlanayBwEnum.BW216;

Sets the bandwidth of the EDMG single carrier signal that is a multiple of 2.16 GHz.

bw: BW216 | BW432 BW216 2.16 GHz bandwidth BW432 Requires R&S SMW-K555. 4.32 GHz bandwidth

int Cconfig#
// SCPI: [SOURce<HW>]:BB:WLAY:PCONfig:HDA:CCONfig
int value = driver.Source.Bb.Wlay.Pconfig.Hda.Cconfig;
driver.Source.Bb.Wlay.Pconfig.Hda.Cconfig = 1;

Sets the channel configuration that is the configuration 2.16 GHz and 4.32 GHz channels.

channelConfig: integer Range: 1 to 176

double Pchannel#
// SCPI: [SOURce<HW>]:BB:WLAY:PCONfig:HDA:PCHannel
double value = driver.Source.Bb.Wlay.Pconfig.Hda.Pchannel;

Queries the primary channel number as set via the channel configuration, see Table “Channels of an EDMG STA”.

primaryCha: float Range: 1 to 8

int Rtpt#

SequenceLengthEnum Tsl#
// SCPI: [SOURce<HW>]:BB:WLAY:PCONfig:HDA:TSL
SequenceLengthEnum value = driver.Source.Bb.Wlay.Pconfig.Hda.Tsl;
driver.Source.Bb.Wlay.Pconfig.Hda.Tsl = SequenceLengthEnum.LONG;

Sets training sequence length as set with the 2-bit subfield “Sequence Length” of the TRN field.

trnSeqLen: NORMAL | LONG | SHORT NORMAL Normal sequence length of 128 x NCB with subfield value 0. LONG Long sequence length of 256 x NCB with subfield value 1. SHORT Short sequence length of 64 x NCB with subfield value 2.
