// SCPI: SOURce<HW>:PRESet
driver.Source.Preset();
driver.Source.PresetAndWait();
driver.Source.PresetAndWait(1000);

Supported in 2x1x1 configurations:

  • method RsSmw.Sconfiguration.ModeSTANdard

  • method RsSmw.Sconfiguration.ModeADVanced with method RsSmw.Sconfiguration.FadingFAAFBB

Presets all parameters which are related to the selected signal path. Fading simulator (if available) and the transient recorder are only preset by the command *RST.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
