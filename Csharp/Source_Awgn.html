Direct SCPI Members

double Brate#
// SCPI: [SOURce<HW>]:AWGN:BRATe
double value = driver.Source.Awgn.Brate;
driver.Source.Awgn.Brate = 1.0;

Sets the bit rate used for calculation of bit energy to noise power ratio. Valid units are bps, kbps and mabps as well as b/s, kb/s and mab/s.

brate: float Range: 400 to depends on options

double CnRatio#
// SCPI: [SOURce<HW>]:AWGN:CNRatio
double value = driver.Source.Awgn.CnRatio;
driver.Source.Awgn.CnRatio = 1.0;

Sets the carrier/interferer ratio.

cnRatio: float Range: -50 to depends on options

double EnRatio#
// SCPI: [SOURce<HW>]:AWGN:ENRatio
double value = driver.Source.Awgn.EnRatio;
driver.Source.Awgn.EnRatio = 1.0;

Sets the ratio of bit energy to noise power density.

enRatio: float Range: -50 to depends on options, Unit: dB

NoisAwgnModeEnum Mode#
// SCPI: [SOURce<HW>]:AWGN:MODE
NoisAwgnModeEnum value = driver.Source.Awgn.Mode;
driver.Source.Awgn.Mode = NoisAwgnModeEnum.ADD;

Determines how the interfering signal is generated.

mode: ONLY | ADD | CW ADD The AWGN noise signal is added to the baseband signal. ONLY The pure AWGN noise signal is modulated to the carrier. The connection to the baseband is interrupted CW The sine interfering signal is added to the baseband signal.

bool State#
// SCPI: [SOURce<HW>]:AWGN:STATe
bool value = driver.Source.Awgn.State;
driver.Source.Awgn.State = false;

Activates or deactivates the AWGN generator or the corresponding stream. See also “Suffixes in the keywords ENTity<ch> and SOURce<hw>”.

state: 1 | ON | 0| OFF
