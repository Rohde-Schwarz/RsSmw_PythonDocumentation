WlannTxBwEnum Bandwidth#
// SCPI: [SOURce<HW>]:BB:WLNN:BWidth
WlannTxBwEnum value = driver.Source.Bb.Wlnn.Bandwidth;
driver.Source.Bb.Wlnn.Bandwidth = WlannTxBwEnum.BW160;

The command selects the transmission bandwidth. Whenever the bandwidth changes from a higher to a lower one, the frame blocks are validated because some of them could be invalid in the lower bandwidth (invalid TX Mode) .

bwidth: BW20 | BW40 | BW80 | BW160 | BW320 Unit: MHz

void Preset ( )#
void PresetAndWait ( )#
void PresetAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:BB:WLNN:PRESet
driver.Source.Bb.Wlnn.Preset();
driver.Source.Bb.Wlnn.PresetAndWait();
driver.Source.Bb.Wlnn.PresetAndWait(1000);

Sets all parameters of the application to their default values. These values are the *RST values of the commands of the application.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.

state: 1 | ON | 0| OFF
