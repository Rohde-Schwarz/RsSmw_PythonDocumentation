Sets the frequency of the LF signal in method RsSmw.Source.LfOutput.Frequency.Mode CW | FIXed mode. Note:

  • If the LF generator is used as a signal source, the instrument performs the analog modulations (AM/FM/FiM/PM) with this frequency.

  • In sweep mode (method RsSmw.Source.LfOutput.Frequency.Mode SWE) , the frequency is coupled with the sweep frequency.

frequency float Range: 0.1 to depends on options (R&S SMW-K24) , Unit: Hz

lfOutput Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.

double Manual#
// SCPI: [SOURce<HW>]:LFOutput:FREQuency:MANual
double value = driver.Source.LfOutput.Frequency.Manual;
driver.Source.LfOutput.Frequency.Manual = 1.0;

Sets the frequency of the subsequent sweep step if LFO:SWE:MODE MAN. Use a separate command for each sweep step.

manual: float You can select any value within the setting range, where: STARt is set with method RsSmw.Source.LfOutput.Frequency.Start() STOP is set with method RsSmw.Source.LfOutput.Frequency.Stop() Range: STARt to STOP

LfFreqModeEnum Mode#
// SCPI: [SOURce<HW>]:LFOutput:FREQuency:MODE
LfFreqModeEnum value = driver.Source.LfOutput.Frequency.Mode;
driver.Source.LfOutput.Frequency.Mode = LfFreqModeEnum.CW;

Sets the mode for the output of the LF generator frequency, and determines the commands to be used for frequency settings.

mode: CW | FIXed | SWEep CW | FIXed Sets the fixed-frequency mode. CW and FIXed are synonyms. To set the output frequency, use command method RsSmw.Source.LfOutput.Frequency.Set() SWEep Sets sweep mode. To set the frequency, use the commands: method RsSmw.Source.LfOutput.Frequency.Start() and method RsSmw.Source.LfOutput.Frequency.Stop() Or method RsSmw.Source.LfOutput.Frequency.Manual()
