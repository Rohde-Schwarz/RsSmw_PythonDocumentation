Source:Bb:Gnss:Time:Start#

SCPI Commands

[SOURce<HW>]:BB:GNSS:TIME:STARt:TOWeek
[SOURce<HW>]:BB:GNSS:TIME:STARt:WNUMber

// Create a clone of the original group, that exists independently

Direct SCPI Members

TimeBasisEnum Tbasis#
// SCPI: [SOURce<HW>]:BB:GNSS:TIME:STARt:TBASis
TimeBasisEnum value = driver.Source.Bb.Gnss.Time.Start.Tbasis;
driver.Source.Bb.Gnss.Time.Start.Tbasis = TimeBasisEnum.BDT;

Sets the timebase to enter the simulation start time. This timebase is also the timebase for assistance data generation, see method RsSmw.Source.Bb.Gnss.AdGeneration.Gps.ToaData.Tbasis.

systemTime: UTC | GPS | GST | GLO | BDT | NAV

double ToWeek#
// SCPI: [SOURce<HW>]:BB:GNSS:TIME:STARt:TOWeek
double value = driver.Source.Bb.Gnss.Time.Start.ToWeek;
driver.Source.Bb.Gnss.Time.Start.ToWeek = 1.0;

If time base is GPS or GST, sets the simulation start time within week set with the command method RsSmw.Source.Bb.Gnss.Time.Start.Wnumber.

tow: float Number of seconds since the beginning of the week Range: 0 to 604799.999

int Wnumber#
// SCPI: [SOURce<HW>]:BB:GNSS:TIME:STARt:WNUMber
int value = driver.Source.Bb.Gnss.Time.Start.Wnumber;
driver.Source.Bb.Gnss.Time.Start.Wnumber = 1;

If time base is GPS or GST, sets the week number (WN) .

week: integer The weeks are numbered starting from a reference time point (WN_REF=0) , that depends on the navigation standard. Range: 0 to 9999*53
