Determines the control signal that is input at the selected connector. To define the connector direction, use the command method RsSmw.Source.Input.Tm.Direction.Set.

signal TRIGger | CLOCk | FEEDback | DATA CLOCk is available only for TM1 DATA is available only for TM2 (default if custom digital modulation with external serial data is used) FEEDback is available only for TM3 (R&S SMW-B10) /TM2 (R&S SMW-B9)

tmConnector Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
