The command determines the data source for the data fields of enhanced channels with channel coding. If channel coding is not active, the DPCH data source is used (SOURce:BB:W3GPp:BST:CHANnel:DATA) .

data PN9 | PN11 | PN15 | PN16 | PN20 | PN21 | PN23 | DLISt | ZERO | ONE | PATTern | PNxx The pseudo-random sequence generator is used as the data source. Different random sequence lengths can be selected. DLISt A data list is used. The data list is selected with the command method RsSmw.Source.Bb.W3Gpp.Bstation.Enhanced.Channel.Dpch.Tchannel.Data.Dselect.Set(). ZERO | ONE Internal 0 and 1 data is used. PATTern Internal data is used. The bit pattern for the data is defined with the command method RsSmw.Source.Bb.W3Gpp.Bstation.Enhanced.Channel.Dpch.Tchannel.Data.Pattern.Set().

channelNull Repeated capability selector

transportChannelNull Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
