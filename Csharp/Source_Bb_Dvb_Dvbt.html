Direct SCPI Members

double Drate#
// SCPI: [SOURce<HW>]:BB:DVB:DVBT:DRATe
double value = driver.Source.Bb.Dvb.Dvbt.Drate;

Queries the data rate.

drate: float

double Duration#
// SCPI: [SOURce<HW>]:BB:DVB:DVBT:DURation
double value = driver.Source.Bb.Dvb.Dvbt.Duration;

Queries the signal duration.

duration: float

DvbHierarchyModeEnum Hmode#
// SCPI: [SOURce<HW>]:BB:DVB:DVBT:HMODe
DvbHierarchyModeEnum value = driver.Source.Bb.Dvb.Dvbt.Hmode;
driver.Source.Bb.Dvb.Dvbt.Hmode = DvbHierarchyModeEnum.HIErarchical;

Queries the mode for hierarchical coding, that is non-hierachical coding. The current firmware does not support hierarchical coding.

hmode: NHIerarchical Non-hierchical coding using high priority input only.

int Sframes#
// SCPI: [SOURce<HW>]:BB:DVB:DVBT:SFRames
int value = driver.Source.Bb.Dvb.Dvbt.Sframes;
driver.Source.Bb.Dvb.Dvbt.Sframes = 1;

Sets the number of super-frames to be transmitted.

sframes: integer Range: 1 to 1633 (dynamic)
