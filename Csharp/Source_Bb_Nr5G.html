void Preset ( )#
void PresetAndWait ( )#
void PresetAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:BB:NR5G:PRESet
driver.Source.Bb.Nr5G.Preset();
driver.Source.Bb.Nr5G.PresetAndWait();
driver.Source.Bb.Nr5G.PresetAndWait(1000);

Sets all parameters of the application to their default values. These values are the *RST values of the commands of the application.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
