Standard function to append or remove a frame from the table.

sfCfgIxNull Repeated capability selector

DeleteAndWait is the same as Delete, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.

Resets the frame table, that is, removes all frames but the first one and presets the frame central frequency offset and frame bandwidth to the default values.

sfCfgIxNull Repeated capability selector

ResetAndWait is the same as Reset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
