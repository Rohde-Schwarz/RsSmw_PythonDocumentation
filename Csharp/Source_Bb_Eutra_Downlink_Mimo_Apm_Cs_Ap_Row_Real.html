Define the mapping of the antenna ports to the physical antennas.

antPortMapDat 0 | 1 (for AP = 0 to 3) ; float (for AP = 4 | 6 | 15 to 46) The mapping of the first four APs AP0 | 1|2 | 3 depends on the system configuration as follows: With method RsSmw.Sconfiguration.Baseband.Source()SEParate exactly one single AP can be mapped to a BB. With method RsSmw.Sconfiguration.Baseband.Source()COUPled | CPENtity none or exactly one single AP can be mapped to a BB. To map an AP, use the command SOURce1:BB:EUTRa:DL:MIMO:APM:CS:AP0 | 1|2 | 3:ROW0 | 1|2 | 3:REAL 1. The corresponding …:CS:AP0 | 1|2 | 3:ROW0 | 1|2 | 3:IMAG command has no effect. The REAL (Magnitude) and IMAGinary (Phase) values are interdependent. Their value ranges change depending on each other and so that the resulting complex value is as follows: REAL+jIMAGinary <= 1 Otherwise, the values are normalized to Magnitude = 1. Range: -1 to 360
