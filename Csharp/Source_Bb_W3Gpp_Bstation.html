Direct SCPI Members

void Preset ( )

// SCPI: [SOURce<HW>]:BB:W3GPp:BSTation:PRESet
driver.Source.Bb.W3Gpp.Bstation.Preset();
driver.Source.Bb.W3Gpp.Bstation.PresetAndWait();
driver.Source.Bb.W3Gpp.Bstation.PresetAndWait(1000);

The command produces a standardized default for all the base stations. The settings correspond to the *RST values specified for the commands. All base station settings are preset.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
