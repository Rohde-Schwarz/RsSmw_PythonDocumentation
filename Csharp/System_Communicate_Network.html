Direct SCPI Members

string MacAddress#
// SCPI: SYSTem:COMMunicate:NETWork:MACaddress
string value = driver.System.Communicate.Network.MacAddress;
driver.System.Communicate.Network.MacAddress = "abc";

Queries the MAC address of the network adapter. This is a password-protected function. Unlock the protection level 1 to access it. See method RsSmw.System.Protect.State.Set.

macAddress: string
