void Preset ( )

// SCPI: [SOURce<HW>]:BB:C2K:BSTation:PRESet
driver.Source.Bb.C2K.Bstation.Preset();
driver.Source.Bb.C2K.Bstation.PresetAndWait();
driver.Source.Bb.C2K.Bstation.PresetAndWait(1000);

A standardized default for all the base stations (*RST values specified for the commands) . See “Reset All Base Stations” for an overview.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
