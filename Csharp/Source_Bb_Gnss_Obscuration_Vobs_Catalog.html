Source:Bb:Gnss:Obscuration:Vobs:Catalog#

SCPI Commands

[SOURce<HW>]:BB:GNSS:OBSCuration:VOBS:CATalog:PREDefined
[SOURce<HW>]:BB:GNSS:OBSCuration:VOBS:CATalog:USER

Direct SCPI Members

List<string>Predefined#
// SCPI: [SOURce<HW>]:BB:GNSS:OBSCuration:VOBS:CATalog:PREDefined
List<string> value = driver.Source.Bb.Gnss.Obscuration.Vobs.Catalog.Predefined;

Queries the names of predefined files in the system directory. Listed are only the following file types:

  • Obstacles description files (rs_obst)

  • Roadside buildings description files (rs_buil)

List<string>User#
// SCPI: [SOURce<HW>]:BB:GNSS:OBSCuration:VOBS:CATalog:USER
List<string> value = driver.Source.Bb.Gnss.Obscuration.Vobs.Catalog.User;

Queries the names of the user-defined files in the default directory. The default directory is set using command method RsSmw.MassMemory.CurrentDirectory. Listed are the following file types:

  • Obstacles description files (rs_obst)

  • Roadside buildings description files (rs_buil)
