SystConfBbBandwidthEnum BbBw#
// SCPI: SCONfiguration:BBBW
SystConfBbBandwidthEnum value = driver.Sconfiguration.BbBw;
driver.Sconfiguration.BbBw = SystConfBbBandwidthEnum.BB040;

Sets the bandwidth of the baseband signal at the inputs of the fading simulator. The available values depend on the selected MIMO configuration. For example:

  • In MIMO configurations with fewer than 8 channels, the max. baseband bandwidth is 400 MHz.

  • In MIMO configurations with fewer than 4 channels, the max. baseband bandwidth is 800 MHz.

bandwidth: BB040 | BB050 | BB080 | BB100 | BB160 | BB200 | BB800 | BB400 | BB500 | BB1G | BB2G | BB120 | BBOUTDEF | BB240 BB040 | BB050 … Bandwidth in MHz, e.g. 40 MHz. BB1G | BB2G 1 GHz, 2 GHz bandwidth. Available in SISO configurations. BBOUTDEF Bandwidth determined by the signal at the HS DIG I/Q.

SystConfBbBandwidthEnum Cabw#
// SCPI: SCONfiguration:CABW
SystConfBbBandwidthEnum value = driver.Sconfiguration.Cabw;

Queries the resulting channel aggregation bandwidth, i.e. the signal bandwidth at the outputs of the stream mapper. The value is calculated automatically and depends on the selected configuration, the installed options and the selected baseband bandwidth (method RsSmw.Sconfiguration.BbBw) .

bandwidth: BB800 | BB200

SystConfModeClassicEnum Mode#
// SCPI: SCONfiguration:MODE
SystConfModeClassicEnum value = driver.Sconfiguration.Mode;
driver.Sconfiguration.Mode = SystConfModeClassicEnum.ADVanced;

Switches between the operating modes.

mode: ADVanced | STANdard | REGenerator | GNSS | ESEQuencer | BWEXtension ADVanced | STANdard Switches between the and . REGenerator Enables the R&S SMW200A to work as a radar echo generator. The fading simulator is disabled. See “Welcome to the Frontend Control Option”. GNSS Enables the R&S SMW200A to work in GNSS advanced mode. The fading simulator is disabled. See “Welcome to the GNSS Satellite Navigation Options”. ESEQuencer Enables the R&S SMW200A to work in an advanced extended sequencer mode. The fading simulator, the AWGN, the BB input and all baseband digital standards are disabled. See “Welcome to the Extended Sequencer”. BEXTension Enables the R&S SMW200A to generate RF signals with extended bandwidth. These signals typically have bandwidths above 2.4 GHz. See “Welcome to the Frontend Control option”.

void Preset ( )#
void PresetAndWait ( )#
void PresetAndWait ( int opcTimeoutMs )
// SCPI: SCONfiguration:PRESet
driver.Sconfiguration.Preset();
driver.Sconfiguration.PresetAndWait();
driver.Sconfiguration.PresetAndWait(1000);

Presets the signal routing in the baseband section and the fading configuration to the default state.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
