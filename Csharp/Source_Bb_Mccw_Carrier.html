Direct SCPI Members

int Count#
// SCPI: [SOURce<HW>]:BB:MCCW:CARRier:COUNt
int value = driver.Source.Bb.Mccw.Carrier.Count;

Sets the number of carriers in the multi carrier CW signal.

count: integer Range: 1 to 160001

class Phase_Data

Structure for reading output parameters.

int CarrierIndex

integer Range: 0 to lastCarrier

double Phase

float Range: 0 to 359.99, Unit: DEG

Phase_Data Phase#
// SCPI: [SOURce<HW>]:BB:MCCW:CARRier:PHASe
Phase_Data value = driver.Source.Bb.Mccw.Carrier.Phase;

For disabled optimization of the crest factor, sets the start phase of the selected carrier.

For return value, see the help for Phase_Data structure arguments

class Power_Data

Structure for reading output parameters.

int CarrierIndex

integer Range: 0 to lastCarrier

double Power

float Range: -80 to 0

Power_Data Power#
// SCPI: [SOURce<HW>]:BB:MCCW:CARRier:POWer
Power_Data value = driver.Source.Bb.Mccw.Carrier.Power;

Sets the power of the selected carrier.

For return value, see the help for Power_Data structure arguments

double Spacing#
// SCPI: [SOURce<HW>]:BB:MCCW:CARRier:SPACing
double value = driver.Source.Bb.Mccw.Carrier.Spacing;

Sets the carrier spacing.

spacing: float Value range depends on the available bandwidth and the number of carriers, see “Cross-reference between total bandwidth, carrier spacing, and number of carriers”. Range: 0 to depends on options, for example 120E6 (R&S SMW-B10)

class State_Data

integer Range: 0 to lastCarrier

State_Data State#

For return value, see the help for State_Data structure arguments
