Direct SCPI Members

double Delay

Specifies the trigger delay (expressed in symbols) for triggering by the trigger signal from the other path.

delay: float Range: 0 to 2147483647

int Inhibit
// SCPI: [SOURce<HW>]:BB:DM:TRIGger:OBASeband:INHibit
int value = driver.Source.Bb.Dm.Trigger.Obaseband.Inhibit;
driver.Source.Bb.Dm.Trigger.Obaseband.Inhibit = 1;

Specifies the number of symbols by which a restart is inhibited. This command applies only for triggering by the second path.

inhibit: integer Range: 0 to 67108863, Unit: symbol
