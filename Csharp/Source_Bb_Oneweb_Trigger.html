TrigSourEnum Source#
// SCPI: [SOURce<HW>]:BB:ONEWeb:TRIGger:SOURce
TrigSourEnum value = driver.Source.Bb.Oneweb.Trigger.Source;
driver.Source.Bb.Oneweb.Trigger.Source = TrigSourEnum.BBSY;

Selects the trigger signal source and determines the way the triggering is executed. Provided are:[[/LISTINTRO]]

  • Internal triggering by a command (INTernal)

  • External trigger signal via one of the local or global connectors

  • EGT1 | EGT2: External global trigger - EGC1 | EGC2: External global clock - ELTRigger: External local trigger - ELCLock: External local clock

  • Internal triggering by a signal from the other basebands (INTA | INTB)

  • OBASeband | BEXTernal | EXTernal: Setting only Provided only for backward compatibility with other Rohde & Schwarz signal generators. The R&S SMW accepts these values and maps them automatically as follows: EXTernal = EGT1, BEXTernal = EGT2, OBASeband = INTA or INTB (depending on the current baseband)

trigSour: INTB | INTernal | OBASeband | EGT1 | EGT2 | EGC1 | EGC2 | ELTRigger | INTA | ELCLock | BEXTernal | EXTernal

DmTrigModeEnum Sequence#

[[LISTINTRO]]Selects the trigger mode:

  • AUTO = auto

  • RETRigger = retrigger

  • AAUTo = armed auto

  • ARETrigger = armed retrigger

  • SINGle = single

trigMode: AUTO | RETRigger | AAUTo | ARETrigger | SINGle
