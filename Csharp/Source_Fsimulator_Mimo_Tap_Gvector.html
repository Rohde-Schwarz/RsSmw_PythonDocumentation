Source:Fsimulator:Mimo:Tap:Gvector<GainVectorRepCap>#

RepCap Settings

// Range: Nr1 .. Nr8
var rc = driver.Source.Fsimulator.Mimo.Tap.Gvector.RepCapGainVector;
driver.Source.Fsimulator.Mimo.Tap.Gvector.RepCapGainVector = GainVectorRepCap.Nr1;

SCPI Commands

[SOURce<HW>]:FSIMulator:MIMO:TAP<CH>:GVECtor:PRESet

Cloning the Group

// Create a clone of the original group, that exists independently
var gvector2 = driver.Source.Fsimulator.Mimo.Tap.Gvector.Clone();

Direct SCPI Members

void Preset ( MimoTapRepCap mimoTap )
void PresetAndWait ( MimoTapRepCap mimoTap )
void PresetAndWait ( MimoTapRepCap mimoTap, int opcTimeoutMs )
// SCPI: [SOURce<HW>]:FSIMulator:MIMO:TAP<CH>:GVECtor:PRESet
driver.Source.Fsimulator.Mimo.Tap.Gvector.Preset(MimoTapRepCap.Default);
driver.Source.Fsimulator.Mimo.Tap.Gvector.PresetAndWait(MimoTapRepCap.Default);
driver.Source.Fsimulator.Mimo.Tap.Gvector.PresetAndWait(MimoTapRepCap.Default, 1000);

Presets the vector matrix to a unitary matrix.

mimoTap Repeated capability selector

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
