MassMemory:Store:State#

SCPI Commands

MMEMory:STORe:STATe

Direct SCPI Members

void Set ( int dataSet, string destinationFile )#
// SCPI: MMEMory:STORe:STATe
driver.MassMemory.Store.State.Set(1, "abc");

Saves the current instrument setting in the specified file. Save the instrument settings to the internal memory with the same number using the common command *SAV.

dataSet Corresponds to the specific number defined with the *SAV command, e.g. *SAV 4.

destinationFile Filename with file extension savrcltxt.
