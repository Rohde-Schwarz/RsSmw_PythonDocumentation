Direct SCPI Members

TetraChnnlTypeEnum Ctype#
// SCPI: [SOURce<HW>]:BB:TETRa:CTYPe
TetraChnnlTypeEnum value = driver.Source.Bb.Tetra.Ctype;
driver.Source.Bb.Tetra.Ctype = TetraChnnlTypeEnum.CH0;

(for “Test Model” set to T1 or T4) Determines the channel type.

ctype: CH0 | CH1 | CH2 | CH3 | CH4 | CH7 | CH8 | CH9 | CH10 | CH11 | CH21 | CH22 | CH23 | CH24 | CH25 | CH26 | CH27

TetraDwnBrstTypeEnum DbType#
// SCPI: [SOURce<HW>]:BB:TETRa:DBTYpe
TetraDwnBrstTypeEnum value = driver.Source.Bb.Tetra.DbType;
driver.Source.Bb.Tetra.DbType = TetraDwnBrstTypeEnum.CONTinuous;

(in Downlink “Link Direction” and for “Test Model” set to T2 or User Defined) Determines the downlink burst type.

dbType: CONTinuous | DCONtinuous

UpDownDirectionEnum Ldirection#
// SCPI: [SOURce<HW>]:BB:TETRa:LDIRection
UpDownDirectionEnum value = driver.Source.Bb.Tetra.Ldirection;
driver.Source.Bb.Tetra.Ldirection = UpDownDirectionEnum.DOWN;

Selects the transmission direction. This parameter determines the available “Channel Types”.

ldirection: DOWN | UP DOWN The transmission direction selected is from the base station (BS) to the terminal (MS) . The signal corresponds to that of a BS. UP The transmission direction selected is from MS to the BS. The signal corresponds to that of a terminal.

TetraModulTypeEnum Mtype#
// SCPI: [SOURce<HW>]:BB:TETRa:MTYPe
TetraModulTypeEnum value = driver.Source.Bb.Tetra.Mtype;
driver.Source.Bb.Tetra.Mtype = TetraModulTypeEnum.PHASe;

(for “Test Model” set to User Defined) Determines the modulation type, “Phase” or “QAM.”

mtype: PHASe | QAM PHASe The T2 test signal is a pi/4-DQPSK modulated continuous radio signal. QAM The T2 test signal is 4-QAM, 16-QAM or 64-QAM modulated and spans a bandwidth of 25kHz, 50kHz, 100kHz or 150kHz.

void Preset ( )#
void PresetAndWait ( )#
void PresetAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:BB:TETRa:PRESet
driver.Source.Bb.Tetra.Preset();
driver.Source.Bb.Tetra.PresetAndWait();
driver.Source.Bb.Tetra.PresetAndWait(1000);

Sets the parameters of the digital standard to their (*RST values specified for the commands) . Not affected is the state set with the command method RsSmw.Source.Bb.Tetra.State.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.

int Slength#
// SCPI: [SOURce<HW>]:BB:TETRa:SLENgth
int value = driver.Source.Bb.Tetra.Slength;
driver.Source.Bb.Tetra.Slength = 1;

Selects the sequence length of the arbitrary waveform file in the number of multiframes. One multiframe is the minimum sequence length for a T1 signal.

slength: integer Range: 1 to depends on carrier bandwidth

bool State#
// SCPI: [SOURce<HW>]:BB:TETRa:STATe
bool value = driver.Source.Bb.Tetra.State;
driver.Source.Bb.Tetra.State = false;

Activates the standard and deactivates all the other digital standards and digital modulation modes in the same path.

state: 1 | ON | 0| OFF
