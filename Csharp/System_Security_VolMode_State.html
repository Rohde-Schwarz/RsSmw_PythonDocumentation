System:Security:VolMode:State#

SCPI Commands

SYSTem:SECurity:VOLMode:[STATe]

Direct SCPI Members

bool Get ( )#
void Set ( string secPassWord, bool mmemProtState )#
// SCPI: SYSTem:SECurity:VOLMode:[STATe]
// Get:
bool value = driver.System.Security.VolMode.State.Get();
// Set:
driver.System.Security.VolMode.State.Set("abc", false);

Activates volatile mode, so that no user data can be written to the internal memory permanently. To enable volatile mode, reboot the instrument. Otherwise the change has no effect.

secPassWord string Current security password The default password is 123456.

mmemProtState 0 | 1| OFF | ON
