// SCPI: [SOURce<HW>]:EFRontend:EXTDevice:REFResh
driver.Source.Efrontend.ExtDevice.Refresh.Set();
driver.Source.Efrontend.ExtDevice.Refresh.SetAndWait();
driver.Source.Efrontend.ExtDevice.Refresh.SetAndWait(1000);

Updates the external devices connected to the external frontend. Use this command before the query method RsSmw.Source.Efrontend.ExtDevice.List.

SetAndWait is the same as Set, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
