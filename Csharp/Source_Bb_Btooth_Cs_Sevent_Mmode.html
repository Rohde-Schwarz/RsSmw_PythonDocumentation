Sets the main mode for the first subevent SEVent0. All following subevents use the same main mode. For an overview on available submodes per main mode, see Table “CS step main modes and submodes”.

mainMode: MODE1 | MODE2 | MODE3 MODE1 Mode-1 mode with no submode available. MODE2 Mode-2 mode with submodes Mode-1 and Mode-3 available. MODE3 Mode-3 mode with submodes Mode-1 and Mode-2 available.

channelNull Repeated capability selector

When you do not use any explicit repeated capability selector, the value is taken from its parent group.
