void CopyAll ( )#
void CopyAllAndWait ( )#
void CopyAllAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:CEMulation:MIMO:COPY:ALL
driver.Source.Cemulation.Mimo.CopyAll();
driver.Source.Cemulation.Mimo.CopyAllAndWait();
driver.Source.Cemulation.Mimo.CopyAllAndWait(1000);

No help available.

CopyAllAndWait is the same as CopyAll, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
