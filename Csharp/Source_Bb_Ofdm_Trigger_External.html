Direct SCPI Members

double Rdelay#
// SCPI: [SOURce<HW>]:BB:OFDM:TRIGger:EXTernal:RDELay
double value = driver.Source.Bb.Ofdm.Trigger.External.Rdelay;

Queries the time (in seconds) an external trigger event is delayed for.

resExtDelaySec: float Range: 0 to 688

double Tdelay#
// SCPI: [SOURce<HW>]:BB:OFDM:TRIGger:EXTernal:TDELay
double value = driver.Source.Bb.Ofdm.Trigger.External.Tdelay;

Specifies the trigger delay for external triggering. The value affects all external trigger signals.

trigExtTimeDel: float Range: 0 to 688, Unit: s

double Delay#
// SCPI: [SOURce<HW>]:BB:OFDM:TRIGger:[EXTernal]:DELay

Specifies the trigger delay.

trigExtDelay: float Range: 0 to 2147483647

Specifies the number of samples by which a restart is to be inhibited following an external trigger event.

trigExtInhibit: integer Range: 0 to dynamic
