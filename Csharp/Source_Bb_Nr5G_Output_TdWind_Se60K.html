Source:Bb:Nr5G:Output:TdWind:Se60K#

SCPI Commands

[SOURce<HW>]:BB:NR5G:OUTPut:TDWind:SE60K:TRTSamples
[SOURce<HW>]:BB:NR5G:OUTPut:TDWind:SE60K:TRTime

Direct SCPI Members

int Trtsamples#
// SCPI: [SOURce<HW>]:BB:NR5G:OUTPut:TDWind:SE60K:TRTSamples
int value = driver.Source.Bb.Nr5G.Output.TdWind.Se60K.Trtsamples;

Queries the number of transition samples. The next to last block in the command syntax indicates the used SCS and CP combination.

  • DL: SE<SCS>K, where E indicates the extended CP or for normal CP, the designation is omitted

transitionSampl: integer Range: 0 to 1000

double TrTime#
// SCPI: [SOURce<HW>]:BB:NR5G:OUTPut:TDWind:SE60K:TRTime
double value = driver.Source.Bb.Nr5G.Output.TdWind.Se60K.TrTime;

Sets the transition time when time domain windowing is active. The next to last block in the command syntax indicates the used SCS and CP combination.

  • DL: SE<SCS>K, where E indicates the extended CP or for normal CP, the designation is omitted

transitionTime: float Range: 0 to 1E-5
