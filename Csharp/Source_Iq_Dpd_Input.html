double Cfactor#
// SCPI: [SOURce<HW>]:IQ:DPD:INPut:CFACtor
double value = driver.Source.Iq.Dpd.Input.Cfactor;

Queries the measured values the before and after the enabled digital predistortion.

crestFactor: float The query returns -1000 if the calculation is impossible or there are no measurements results available.
