Direct SCPI Members

int BpFrame#
// SCPI: [SOURce<HW>]:BB:W3GPp:MSTation:ENHanced:DPDCh:BPFRame
int value = driver.Source.Bb.W3Gpp.Mstation.Enhanced.Dpdch.BpFrame;

The command queries the number of data bits in the DPDCH component of the frame at the physical layer. The number of data bits depends on the overall symbol rate.

bpFrame: integer Range: 150 to 9600

bool Interleaver2#
// SCPI: [SOURce<HW>]:BB:W3GPp:MSTation:ENHanced:DPDCh:INTerleaver2
bool value = driver.Source.Bb.W3Gpp.Mstation.Enhanced.Dpdch.Interleaver2;
driver.Source.Bb.W3Gpp.Mstation.Enhanced.Dpdch.Interleaver2 = false;

The command activates or deactivates channel coding interleaver state 2 for all the transport channels. Interleaver state 1 can be activated and deactivated for each channel individually (method RsSmw.Source.Bb.W3Gpp.Mstation.Enhanced.Dpdch.Tchannel.Interleaver.Set) . Note: The interleaver states do not cause the symbol rate to change

interleaver2: 1 | ON | 0| OFF

SymbRateEnum Orate#
// SCPI: [SOURce<HW>]:BB:W3GPp:MSTation:ENHanced:DPDCh:ORATe
SymbRateEnum value = driver.Source.Bb.W3Gpp.Mstation.Enhanced.Dpdch.Orate;
driver.Source.Bb.W3Gpp.Mstation.Enhanced.Dpdch.Orate = SymbRateEnum.D120k;

The command queries the overall symbol rate (Overall Symbol Rate) of the enhanced channels. The value is set with the command method RsSmw.Source.Bb.W3Gpp.Mstation.Dpdch.Orate.Set. This setting also defines the number of active channels, their symbol rates and channelization codes.

orate: D15K | D30K | D60K | D120k | D240k | D480k | D960k | D1920k | D2880k | D3840k | D4800k | D5760k
