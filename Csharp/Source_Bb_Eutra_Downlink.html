Direct SCPI Members

BehUnsSubFramesEnum Bur#
// SCPI: [SOURce<HW>]:BB:EUTRa:DL:BUR
BehUnsSubFramesEnum value = driver.Source.Bb.Eutra.Downlink.Bur;
driver.Source.Bb.Eutra.Downlink.Bur = BehUnsSubFramesEnum.DTX;

Selects either to fill unscheduled resource elements and subframes with dummy data or DTX. In “Mode > eMTC/NB-IoT”, unused resource elements are filled in with DTX.

bur: DUData | DTX

ChannelBandwidthEnum Bw#
// SCPI: [SOURce<HW>]:BB:EUTRa:DL:BW
ChannelBandwidthEnum value = driver.Source.Bb.Eutra.Downlink.Bw;
driver.Source.Bb.Eutra.Downlink.Bw = ChannelBandwidthEnum.BW0_20;

Sets the DL channel bandwidth.

bw: BW1_40 | BW3_00 | BW5_00 | BW10_00 | BW15_00 | BW20_00 | BW0_20 | USER

int ConSubFrames#

Sets the number of configurable subframes.

conSubFrames: integer Range: 1 to 40
