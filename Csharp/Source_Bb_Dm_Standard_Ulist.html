Direct SCPI Members

List<string>Catalog#
// SCPI: [SOURce<HW>]:BB:DM:STANdard:ULISt:CATalog
List<string> value = driver.Source.Bb.Dm.Standard.Ulist.Catalog;

Queries the files with digital modulation respectively user standard settings in the default directory. Listed are files with the file extension dm and dm_stu.

catalog: “filename1,filename2,…” Returns a string of filenames separated by commas.

void Delete ( string filename )#
// SCPI: [SOURce<HW>]:BB:DM:STANdard:ULISt:DELete

void Load ( string filename )#
// SCPI: [SOURce<HW>]:BB:DM:STANdard:ULISt:LOAD
driver.Source.Bb.Dm.Standard.Ulist.Load("abc");

Loads the selected file from the default or the specified directory. Loaded are files with extension dm respectively dm_stu. See also “Handling files in the default or in a specified directory”.

filename string

string Store#
// SCPI: [SOURce<HW>]:BB:DM:STANdard:ULISt:STORe

Saves the current settings into the selected file; the file extension (dm respectively dm_stu) is assigned automatically. See also “Handling files in the default or in a specified directory”.
