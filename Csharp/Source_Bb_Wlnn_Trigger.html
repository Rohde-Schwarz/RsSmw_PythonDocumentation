Direct SCPI Members

TrigRunModeEnum Rmode#
// SCPI: [SOURce<HW>]:BB:WLNN:TRIGger:RMODe
TrigRunModeEnum value = driver.Source.Bb.Wlnn.Trigger.Rmode;

The command queries the current status of signal generation for all trigger modes with IEEE 802.11 WLAN modulation on.

rmode: STOP | RUN STOP The signal is not generated. A trigger event did not occur in the triggered modes, or signal generation was stopped by the command :SOURce1:BB:WLNN:TRIGger:ARM:EXECute (armed trigger modes only) . RUN The signal is generated. A trigger event occurred in the triggered mode.

int Slength#
// SCPI: [SOURce<HW>]:BB:WLNN:TRIGger:SLENgth
int value = driver.Source.Bb.Wlnn.Trigger.Slength;
driver.Source.Bb.Wlnn.Trigger.Slength = 1;

The command defines the length of the signal sequence to be output in the “Single” trigger mode (method RsSmw.Source.Bb.Wlnn.Trigger.Sequence is set to SING) . The input is made in terms of samples. It is possible to output deliberately just part of the frame, an exact sequence of the frame, or a defined number of repetitions of the frame.

slength: integer Range: 1 to (2^32) - 1, Unit: sample

UnitSlBenum SlUnit#
// SCPI: [SOURce<HW>]:BB:WLNN:TRIGger:SLUNit
UnitSlBenum value = driver.Source.Bb.Wlnn.Trigger.SlUnit;
driver.Source.Bb.Wlnn.Trigger.SlUnit = UnitSlBenum.SAMPle;

Defines the unit for the entry of the length of the signal sequence (method RsSmw.Source.Bb.Wlnn.Trigger.Slength) to be output in the single trigger mode (method RsSmw.Source.Bb.Wlnn.Trigger.Sequence is set to SINGle) .

slUnit: SEQuence | SAMPle SEQuence Unit Sequence Length. A single sequence is generated after a trigger event. SAMPle Unit Sample. A single sample is generated after a trigger event.

TrigSourEnum Source#
// SCPI: [SOURce<HW>]:BB:WLNN:TRIGger:SOURce
TrigSourEnum value = driver.Source.Bb.Wlnn.Trigger.Source;
driver.Source.Bb.Wlnn.Trigger.Source = TrigSourEnum.BBSY;

Selects the trigger signal source and determines the way the triggering is executed. Provided are the following trigger sources:[[/LISTINTRO]]

  • INTernal: Internal manual triggering of the instrument

  • INTA | INTB: Internal triggering by a signal from the other basebands

  • External trigger signal via one of the local or global connectors:

  • EGT1 | EGT2: External global trigger - EGC1 | EGC2: External global clock - ELTRigger: External local trigger - ELCLock: External local clock

  • For secondary instruments (SCONfiguration:MULTiinstrument:MODE SEC) , triggering via the external baseband synchronization signal of the primary instrument: SOURce1:BB:ARB:TRIGger:SOURce BBSY

  • OBASeband | BEXTernal | EXTernal: Setting only Provided only for backward compatibility with other Rohde & Schwarz signal generators. The R&S SMW200A accepts these values and maps them automatically as follows: EXTernal = EGT1, BEXTernal = EGT2, OBASeband = INTA or INTB (depending on the current baseband)

source: INTB | INTernal | OBASeband | EGT1 | EGT2 | EGC1 | EGC2 | ELTRigger | INTA | ELCLock | BEXTernal | EXTernal | BBSY

DmTrigModeEnum Sequence#

DmTrigModeEnum value = driver.Source.Bb.Wlnn.Trigger.Sequence;

[[LISTINTRO]]Selects the trigger mode:

  • AUTO = auto

  • RETRigger = retrigger

  • AAUTo = armed auto

  • ARETrigger = armed retrigger

  • SINGle = single

sequence: AUTO | RETRigger | AAUTo | ARETrigger | SINGle
