Source:Bb:Dvb:Setting#

SCPI Commands

[SOURce<HW>]:BB:DVB:SETTing:CATalog
[SOURce<HW>]:BB:DVB:SETTing:DELete
[SOURce<HW>]:BB:DVB:SETTing:LOAD
[SOURce<HW>]:BB:DVB:SETTing:STORe

Direct SCPI Members

List<string>Catalog#
// SCPI: [SOURce<HW>]:BB:DVB:SETTing:CATalog
List<string> value = driver.Source.Bb.Dvb.Setting.Catalog;

Queries the files with settings in the default directory. Listed are files with the file extension dvb. Refer to “Accessing Files in the Default or Specified Directory” for general information on file handling in the default and in a specific directory.

catalog: filename1,filename2,… Returns a string of filenames separated by commas.

void Delete ( string filename )#
// SCPI: [SOURce<HW>]:BB:DVB:SETTing:DELete
driver.Source.Bb.Dvb.Setting.Delete("abc");

Deletes the selected file from the default or specified directory. Deleted are files with the file extension dvb. Refer to “Accessing Files in the Default or Specified Directory” for general information on file handling in the default and in a specific directory.

filename string Filename or complete file path; file extension can be omitted

void Load ( string filename )#
// SCPI: [SOURce<HW>]:BB:DVB:SETTing:LOAD
driver.Source.Bb.Dvb.Setting.Load("abc");

Loads the selected file from the default or the specified directory. Loaded are files with extension dvb. Refer to “Accessing Files in the Default or Specified Directory” for general information on file handling in the default and in a specific directory.

filename string Filename or complete file path; file extension can be omitted

string Store#
// SCPI: [SOURce<HW>]:BB:DVB:SETTing:STORe

driver.Source.Bb.Dvb.Setting.Store = "abc";

Saves the current settings into the selected file; the file extension (dvb) is assigned automatically. Refer to “Accessing Files in the Default or Specified Directory” for general information on file handling in the default and in a specific directory.

Filename: string Filename or complete file path
