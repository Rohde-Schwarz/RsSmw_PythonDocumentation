// SCPI: TRIGger<HW>:LFFSweep
driver.Trigger.LffSweep.Set(InputIxRepCap.Default);
driver.Trigger.LffSweep.SetAndWait(InputIxRepCap.Default);
driver.Trigger.LffSweep.SetAndWait(InputIxRepCap.Default, 1000);

Executes an LF frequency sweep in the following configuration:

  • method RsSmw.Trigger.LffSweep.Source.Set SING

  • LFO:SWE:MODE AUTO

inputIx Repeated capability selector

SetAndWait is the same as Set, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
