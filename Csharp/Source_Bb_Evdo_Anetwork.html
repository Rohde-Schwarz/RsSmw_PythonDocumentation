Direct SCPI Members

bool CpMode#
// SCPI: [SOURce<HW>]:BB:EVDO:ANETwork:CPMode
bool value = driver.Source.Bb.Evdo.Anetwork.CpMode;
driver.Source.Bb.Evdo.Anetwork.CpMode = false;

Enables or disables a special mode within the 1xEV-DO generator. Note: During the special mode, all other parameters do not affect the signal output.

cpMode: 1 | ON | 0| OFF

int OuCount#
// SCPI: [SOURce<HW>]:BB:EVDO:ANETwork:OUCount
int value = driver.Source.Bb.Evdo.Anetwork.OuCount;
driver.Source.Bb.Evdo.Anetwork.OuCount = 1;

Sets the number of additional users (beyond the four defined users) that appear in the MAC Channel.

ouCount: integer Range: 0 to 55 for physical layer subtype 0&1) , 0 to 110 for physical layer subtype 2, 0 to 360 for physical layer subtype 3

EvdoLayerDnEnum SubType#
// SCPI: [SOURce<HW>]:BB:EVDO:ANETwork:SUBType
EvdoLayerDnEnum value = driver.Source.Bb.Evdo.Anetwork.SubType;
driver.Source.Bb.Evdo.Anetwork.SubType = EvdoLayerDnEnum.S1;

Selects the physical layer subtype. Note: The physical layer subtype settings can be queried per user.

subType: S1 | S2 | S3
