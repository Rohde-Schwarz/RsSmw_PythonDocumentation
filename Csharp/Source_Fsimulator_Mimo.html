string Capability#

string value = driver.Source.Fsimulator.Mimo.Capability;

Queries the supported MIMO configurations.

mimoCapability: string

void CopyAll ( )#
void CopyAllAndWait ( )#
void CopyAllAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:FSIMulator:MIMO:COPY:ALL
driver.Source.Fsimulator.Mimo.CopyAll();
driver.Source.Fsimulator.Mimo.CopyAllAndWait();
driver.Source.Fsimulator.Mimo.CopyAllAndWait(1000);

Applies the matrix values of the current tap to all taps.

CopyAllAndWait is the same as CopyAll, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.

FadMimoSubSetEnum Subset#
// SCPI: [SOURce<HW>]:FSIMulator:MIMO:SUBSet
FadMimoSubSetEnum value = driver.Source.Fsimulator.Mimo.Subset;
driver.Source.Fsimulator.Mimo.Subset = FadMimoSubSetEnum.ALL;

In 8x8 or 4x4 MIMO configuration with higher fading bandwidth, sets the subset of MIMO channels that is calculated by the particular R&S SMW200A.

subset: SET2 | SET1 | ALL
