BbImpOptModeRangeFresponseEnum Mode#
// SCPI: [SOURce<HW>]:CORRection:FRESponse:RF:OPTimization:MODE
BbImpOptModeRangeFresponseEnum value = driver.Source.Correction.Fresponse.Rf.Optimization.Mode;
driver.Source.Correction.Fresponse.Rf.Optimization.Mode = BbImpOptModeRangeFresponseEnum.FAST;

Sets the optimization mode for frequency response correction. This optimization mode also uses the I/Q modulator and vice versa via the command: SOURce<hw>:BB:IMPairment:OPTimization:MODE See “Optimization Mode”.

freqRespOptMode: FAST | QHIGh | QHTable FAST Optimization by compensation for I/Q skew. QHTable Requires an active connection between an R&S SZU and the R&S SMW200A. Improves optimization while maintaining the modulation speed. QHIGh Optimization by compensation for I/Q skew and frequency response correction. This mode interrupts the RF signal. Do not use it in combination with the uninterrupted level settings and strictly monotone modes RF level modes. These RF level modes can be set with the following command: [:SOURcehw]:POWer:LBEHaviour *RST: QHIGh or QHTable with an R&S SZU connected, see above.
