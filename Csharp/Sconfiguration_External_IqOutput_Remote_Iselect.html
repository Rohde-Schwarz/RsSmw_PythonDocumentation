Sconfiguration:External:IqOutput:Remote:Iselect#

SCPI Commands

SCONfiguration:EXTernal:IQOutput<CH>:REMote:ISELect

Direct SCPI Members

class Iselect_Data

Structure for setting input parameters. Contains optional set arguments.

string IpartInstrName

String Instrument alias name, as retrieved with the command method RsSmw.Sconfiguration.External.Remote.List(). The name can also be defined with the command method RsSmw.Sconfiguration.External.Remote.Add.Set().

string RfPath

Optional settings argument. String Determines the used RF output of the external instrument.
