// SCPI: [SOURce<HW>]:BB:GNSS:LOGGing:OFFLine:ABORt
driver.Source.Bb.Gnss.Logging.Offline.Abort();
driver.Source.Bb.Gnss.Logging.Offline.AbortAndWait();
driver.Source.Bb.Gnss.Logging.Offline.AbortAndWait(1000);

Logging files are created and saved. Files with the same name are overwritten. To stop the generation, send method RsSmw.Source.Bb.Gnss.Logging.Offline.Abort.

AbortAndWait is the same as Abort, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
