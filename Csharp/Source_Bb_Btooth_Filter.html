Direct SCPI Members

string Filters#
// SCPI: [SOURce<HW>]:BB:BTOoth:FILTer:FILTers
string value = driver.Source.Bb.Btooth.Filter.Filters;

Queries all configured baseband filters. These filters are the common GFSK baseband filter and, for some EDR packets, a DPSK filter. See also Table “DPSK filter for Bluetooth EDR packets”.

filters: string

string Mindex#
// SCPI: [SOURce<HW>]:BB:BTOoth:FILTer:MINDex
string value = driver.Source.Bb.Btooth.Filter.Mindex;

Queries the modulation index resulting from the entered frequency deviation value.

mindex: string

string Mtype#
// SCPI: [SOURce<HW>]:BB:BTOoth:FILTer:MTYPe
string value = driver.Source.Bb.Btooth.Filter.Mtype;

Queries the modulation type used for the current packet selection.

mtype: string

DmFilterBenum Type#
// SCPI: [SOURce<HW>]:BB:BTOoth:FILTer:TYPE
DmFilterBenum value = driver.Source.Bb.Btooth.Filter.Type;

Selects the filters used for Pi/4 DQPSK and 8DPSK modulations. This opens a selection window containing all the filters available to the instrument.

type: RCOSine | COSine | GAUSs | LGAuss | CONE | COF705 | COEQualizer | COFequalizer | C2K3x | APCO25 | SPHase | RECTangle | PGAuss | LPASs | DIRac | ENPShape | EWPShape
