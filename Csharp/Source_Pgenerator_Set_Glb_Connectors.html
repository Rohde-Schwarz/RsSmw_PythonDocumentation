// SCPI: SOURce<HW>:PGENerator:SET:GLB:CONNectors
driver.Source.Pgenerator.Set.Glb.Connectors.Set();
driver.Source.Pgenerator.Set.Glb.Connectors.SetAndWait();
driver.Source.Pgenerator.Set.Glb.Connectors.SetAndWait(1000);

Routes the pulse input signal and the pulse output signal to a global connector. By default, routes the pulse input to “USER 4” (“Signal” > “Pulse In”) and the pulse output to “USER 5” (“Signal” > “Pulse Out”) .

SetAndWait is the same as Set, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
