WlanadDmgPhyModeEnum DpMode#

Sets the DMG/EDMG PHY mode.

dpMode: CONTrol | SINGle | ESINgle CONTrol DMG control PHY mode SINGle DMG SC PHY mode ESINgle EDMG SC PHY mode

WlanadFrameTypeEnum Ftype#
// SCPI: [SOURce<HW>]:BB:WLAD:FTYPe

driver.Source.Bb.Wlad.Ftype = WlanadFrameTypeEnum.BEACon;

Queries the IEEE 802.11ad/ay frame type. All frames are data frames.

ftype: DATA

double Itime#
// SCPI: [SOURce<HW>]:BB:WLAD:ITIMe
double value = driver.Source.Bb.Wlad.Itime;
driver.Source.Bb.Wlad.Itime = 1.0;

Sets the idle time, the time delay between the frames.

itime: float Range: 0 to 0.01

void Preset ( )#
void PresetAndWait ( )#
void PresetAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:BB:WLAD:PRESet
driver.Source.Bb.Wlad.Preset();
driver.Source.Bb.Wlad.PresetAndWait();
driver.Source.Bb.Wlad.PresetAndWait(1000);

Sets the parameters of the digital standard to their default values (*RST values specified for the commands) . Not affected is the state set with the command BB:WLAD:STATe.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
