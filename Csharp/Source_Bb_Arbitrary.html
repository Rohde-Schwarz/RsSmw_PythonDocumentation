Direct SCPI Members

ArbModeEnum Mode#
// SCPI: [SOURce<HW>]:BB:ARBitrary:MODE
ArbModeEnum value = driver.Source.Bb.Arbitrary.Mode;
driver.Source.Bb.Arbitrary.Mode = ArbModeEnum.ESTReaming;

Defines the mode of the ARB application.

arbMode: STANdard | EUPLoad | ESTReaming STANdard ARB standard mode using a waveform file as an internal baseband source. EUPLoad ARB Ethernet upload mode for uploading waveform files via the external QSFP+ interface. ESTReaming ARB Ethernet streaming mode for I/Q streaming via the external QSFP+ interface.

void Preset ( )#
void PresetAndWait ( )#
void PresetAndWait ( int opcTimeoutMs )
// SCPI: [SOURce<HW>]:BB:ARBitrary:PRESet
driver.Source.Bb.Arbitrary.Preset();
driver.Source.Bb.Arbitrary.PresetAndWait();
driver.Source.Bb.Arbitrary.PresetAndWait(1000);

Sets all ARB generator parameters to their default values.

PresetAndWait is the same as Preset, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.

bool value = driver.Source.Bb.Arbitrary.State;
driver.Source.Bb.Arbitrary.State = false;

Enables the ARB generator. A waveform must be selected before the ARB generator is activated.

state: 1 | ON | 0| OFF
