Direct SCPI Members

double Dot#
// SCPI: [SOURce<HW>]:FSIMulator:SCM:DOT
double value = driver.Source.Fsimulator.Scm.Dot;
driver.Source.Fsimulator.Scm.Dot = 1.0;

Sets the direction of travel of the mobile station.

dirOfTravel: float Range: 0 to 359.9

double Phi#
// SCPI: [SOURce<HW>]:FSIMulator:SCM:PHI
double value = driver.Source.Fsimulator.Scm.Phi;
driver.Source.Fsimulator.Scm.Phi = 1.0;

Sets the travel azimuth angle.

scmPhi: float Range: 0 to 359.9

double Sigma#
// SCPI: [SOURce<HW>]:FSIMulator:SCM:SIGMa
double value = driver.Source.Fsimulator.Scm.Sigma;
driver.Source.Fsimulator.Scm.Sigma = 1.0;

Sets the lognormal shadow fading standard deviation, applied as a common parameter to the paths.

sigma: float Range: 0 to 20

speed: float Range: 0 to 27778

// SCPI: [SOURce<HW>]:FSIMulator:SCM:THETa

scmTheta: float Range: 0 to 179.9
