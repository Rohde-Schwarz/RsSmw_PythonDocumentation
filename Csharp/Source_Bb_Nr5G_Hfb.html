Direct SCPI Members

int AdjCmd#

int Baseband#
// SCPI: [SOURce<HW>]:BB:NR5G:HFB:BASeband
int value = driver.Source.Bb.Nr5G.Hfb.Baseband;

In serial mode, required for multiplexing serial commands for different basebands to one feedback line. See also Example “Configuring the “Baseband Selector” for the 2 Tx antenna ports test cases”.

fbBaseband: integer Range: 0 to 3

// SCPI: [SOURce<HW>]:BB:NR5G:HFB:CONNector

fbConnector: LOCal LOCal T/M 3 connector

int CsRate#
// SCPI: [SOURce<HW>]:BB:NR5G:HFB:CSRate
int value = driver.Source.Bb.Nr5G.Hfb.CsRate;

Defines a custom serial rate. Prerequisites for this command

  • Select a custom serial rate (method RsSmw.Source.Bb.Nr5G.Hfb.SymbolRate) .

If you have defined one of the predefined serial rates, the command queries the selected serial rate.

double Delay#
// SCPI: [SOURce<HW>]:BB:NR5G:HFB:DELay
double value = driver.Source.Bb.Nr5G.Hfb.Delay;

Sets the point in time when the feedback can be sent to the instrument.

fbUserDelay: float Range: -20 to -1.0

bool HpnMode#
// SCPI: [SOURce<HW>]:BB:NR5G:HFB:HPNMode
bool value = driver.Source.Bb.Nr5G.Hfb.HpnMode;

Enables or disables the HARQ process number (HPN) mode. When the “HPN Mode” is set to active, the additional user delay is set to -1.00 Slots and made unchangeable. An additional “HARQ Process Number”parameter is accessible in the PUSCH settings (“PDSCH and PUSCH scheduling commands”) .

hpnMode: 1 | ON | 0| OFF

string LogPath#
// SCPI: [SOURce<HW>]:BB:NR5G:HFB:LOGPath
string value = driver.Source.Bb.Nr5G.Hfb.LogPath;

Defines the output folder on the device for the log files.

logGenOutputPath: string

bool LogState#
// SCPI: [SOURce<HW>]:BB:NR5G:HFB:LOGState
bool value = driver.Source.Bb.Nr5G.Hfb.LogState;

Enables the R&S SMW200A to create and store debug reports, i.e. log files with detailed information on the real-time feedback. The instrument generates two types of reports:[[/LISTINTRO]]

  • Transmission report - This file contains information about what is sent (e.g. redundancy versions) during the first 100 slots after triggering. - File is created after the 100 slots are sent.

  • Reception report[[LISTINTRO]]

    • This file contains information about the first 100 received commands.

    • File is created after 100 commands are successfully received.

Use these debug files for troubleshooting of complex real-time feedback tests.

logGenState: 1 | ON | 0| OFF

FeedbackModeWithEthernetEnum Mode#
// SCPI: [SOURce<HW>]:BB:NR5G:HFB:MODE
FeedbackModeWithEthernetEnum value = driver.Source.Bb.Nr5G.Hfb.Mode;

Enables real-time feedback and determines the mode of the feedback line.

fbMode: OFF | SERial | S3X8 ETH Ethernet feedback mode. OFF Feedback is off. SERial Serial feedback mode. S3X8 Serial 3x8 feedback mode.

double Pdelay#
// SCPI: [SOURce<HW>]:BB:NR5G:HFB:PDELay
double value = driver.Source.Bb.Nr5G.Hfb.Pdelay;

Sets a delay to the slot to which the timing adjustment command (TA) is applied. For example, if “Processing Delay” is set to -2.00 and the TA is received in slot number 6, after processing, the TA is transmitted in slot number 8. If “TA State” > “Off”, the value set for “Feedback Delay” is used for “Processing Delay”.

processingDelay: float Range: -20 to -1

FeedbackRateAllEnum SymbolRate#
// SCPI: [SOURce<HW>]:BB:NR5G:HFB:SRATe
FeedbackRateAllEnum value = driver.Source.Bb.Nr5G.Hfb.SymbolRate;

Sets the bit rate of the serial transmission. For test cases with high subcarrier spacing (SCS) and short slot duration, a serial rate of 115.2 kbps is insufficient. We recommend that you use higher serial rate so that at least one feedback command per slot is received.

bool TaMode#
// SCPI: [SOURce<HW>]:BB:NR5G:HFB:TAMode
bool value = driver.Source.Bb.Nr5G.Hfb.TaMode;

Enables timing advance (TA) adjustment for the selected feedback mode. The TA adjustment uses the “Processing Delay” to define a new timing advance value for advancing or delaying the UL transmission.

taMode: 1 | ON | 0| OFF
