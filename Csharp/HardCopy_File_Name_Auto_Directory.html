HardCopy:File:Name:Auto:Directory#

SCPI Commands

HCOPy:FILE:[NAME]:AUTO:DIRectory:CLEar
HCOPy:FILE:[NAME]:AUTO:DIRectory

Direct SCPI Members

void Clear ( )#
void ClearAndWait ( )#
void ClearAndWait ( int opcTimeoutMs )
// SCPI: HCOPy:FILE:[NAME]:AUTO:DIRectory:CLEar
driver.HardCopy.File.Name.Auto.Directory.Clear();
driver.HardCopy.File.Name.Auto.Directory.ClearAndWait();
driver.HardCopy.File.Name.Auto.Directory.ClearAndWait(1000);

Deletes all files with extensions bmp, jpg, png and xpm in the directory set for automatic naming.

ClearAndWait is the same as Clear, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.

string Value#
// SCPI: HCOPy:FILE:[NAME]:AUTO:DIRectory
string value = driver.HardCopy.File.Name.Auto.Directory.Value;
driver.HardCopy.File.Name.Auto.Directory.Value = "abc";

Determines the path to save the hard copy, if you have enabled Automatic Naming. If the directory does not yet exist, the instrument automatically creates a new directory, using the instrument name and /var/user/ by default.
