driver.Source.Bb.Nfc.Cblock.Copy(CommandBlockRepCap.Default);
driver.Source.Bb.Nfc.Cblock.CopyAndWait(CommandBlockRepCap.Default);
driver.Source.Bb.Nfc.Cblock.CopyAndWait(CommandBlockRepCap.Default, 1000);

Copies a command block for later use.

commandBlock Repeated capability selector

CopyAndWait is the same as Copy, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.

commandBlock Repeated capability selector
