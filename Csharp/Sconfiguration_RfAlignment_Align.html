// SCPI: SCONfiguration:RFALignment:ALIGn
driver.Sconfiguration.RfAlignment.Align.Set();
driver.Sconfiguration.RfAlignment.Align.SetAndWait();
driver.Sconfiguration.RfAlignment.Align.SetAndWait(1000);

If a valid setup is loaded and RF ports alignment is enabled, sends the multi instrument trigger signal to all instruments to synchronize the basebands of the instruments.

SetAndWait is the same as Set, but waits for the operation to complete. The optional entered opcTimeoutMs is only valid for this call. If you omit the opcTimeoutMs, the method uses the settable value RsSmw.Utilities.OpcTimeout.
