Disconnect#

SCPI Command :

SCONfiguration:EXTernal:IQOutput<CH>:REMote:DISConnect
Commands in total: 1
Subgroups: 0
Direct child commands: 1
set ( iqConnector=IqConnector.Default ) → None
set_with_opc ( iqConnector=IqConnector.Default, opc_timeout_ms: int = -1 ) → None
# SCONfiguration:EXTernal:IQOutput<CH>:REMote:DISConnect
# set:
driver.sconfiguration.external.iqOutput.remote.disconnect.set(iqConnector = repcap.IqConnector.Default)
# set_with_opc:
driver.sconfiguration.external.iqOutput.remote.disconnect.set_with_opc(iqConnector = repcap.IqConnector.Default, opc_timeout_ms = 3000)

Disconnects the selected remote connection. To disconnect all remote connections at once, use the command method RsSmw.sconfiguration.external.remote.disconnect.all.set() .

set_with_opc() does the same as set(), but waits for the operation to complete before continuing further. Use the RsSmw.utilities.opc_timeout to set the timeout value.

Parameters:

  • iqConnector – optional repeated capability selector. Default value: Nr1 (settable in the interface ‘IqOutput’)

  • opc_timeout_ms – Maximum time to wait in milliseconds, valid only for this call.
